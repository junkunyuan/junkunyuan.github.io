Recast the self-built target of MeanFlow as plain velocity regression, and make its fixed guidance scale one more condition at test time.
Insight. MeanFlow's target leaks the true velocity through its input. A setting fixed before training, like CFG, cannot change at test time.

  • MeanFlow's target (§3, Eq. 6–7). With noise e and data x, the average velocity u over [r,t], r≤t, and the instantaneous v satisfy u=v−(t−r)JVP(u;v) Eq. (4–5). MeanFlow fits utgt=(e−x)−(t−r)JVP(uθ;e−x) Eq. (6) by 𝔼‖uθ−sg(utgt)‖2 Eq. (7) (sg: stop-gradient).

  • An equivalent v-loss (§4.1, Eq. 9–10). Solve the identity for v, v=u+(t−r)du/dt Eq. (8), to get Vθ≜uθ+(t−r)JVPsg(uθ;e−x) Eq. (9), where JVPsg is its stop-gradient form. The loss 𝔼‖Vθ−(e−x)‖2 Eq. (10) is a v-loss re-parameterized by u-pred, equivalent to Eq. (6–7).

  • The illegitimate input (Eq. 11). In fact, Vθ is Vθ(zt,e−x). It uses the conditional velocity, which no regressor of zt may use.

  • Network-predicted tangent (Eq. 12). Vθ(zt)≜uθ(zt)+(t−r)JVPsg(uθ;vθ): both arguments are now network outputs of zt alone.

  • Two sources of vθ (§4.1). vθ uses the free boundary condition vθ(zt,t)≡uθ(zt,t,t) or an 8-layer v-head on a flow-matching loss.

  • Guidance as a condition (§4.2, Eq. 15). MeanFlow fixes the scale ω of the guided velocity for the class c, vcfg(zt∣c)=ωv(zt∣c)+(1−ω)v(zt) Eq. (13), before training. iMF makes ω an input, Vθ(·∣c,ω)≜uθ(zt∣c,ω)+(t−r)JVPsg Eq. (15), with ω~p(ω)∝ω−β on [1,8] for a skew β.

  • The guided target (App. A, Eq. 17). vtgt=(e−x)+(1−1/ω)(uθ(zt∣t,t,c)−uθ(zt∣t,t,∅)) for the null class ∅. ω=1 is no guidance.

  • Guidance interval (§4.2). Ω={ω,tmin,tmax} with tmin~U[0,0.5] and tmax~U[0.5,1]. Outside it, ω=1, and the r=t rows span [0,1].

  • In-context conditioning (Eq. 16). uθ(zt∣r,t,c,Ω) takes conditions as tokens, 8 for the class and 4 per other, without adaLN-zero.

  • Experiments (§5). On ImageNet-256 from scratch, iMF-XL/2 gets FID 1.72 at 1-NFE (MeanFlow-XL/2: 3.43) and 1.54 at 2-NFE.

  • Size labels mislead (Tab. 2). XL/2 costs 174.6 Gflops in iMF and 119.0 in MeanFlow. At similar FLOPs, M/2 gets 2.27 and 5.01.

def sample_time_steps(bs, time_mu=-0.4, time_sigma=1.0, ratio_r_not_equal_t=0.5):
    time_samples = torch.randn(bs, 2)
    time_samples = torch.sigmoid(time_samples * time_sigma + time_mu)

    sorted_samples, _ = torch.sort(time_samples, dim=1)  # make r < t
    r, t = sorted_samples[:, 0], sorted_samples[:, 1]

    # Set r to t with the probability of r = t.
    fraction_equal = 1.0 - ratio_r_not_equal_t
    equal_mask = torch.rand(bs) < fraction_equal
    r = torch.where(equal_mask, t, r)

    return r, t

def sample_cfg_scale(bs, cfg_beta=1.0, cfg_omega_max=8.0):
    u = torch.rand(bs)
    if cfg_beta == 1.0:
        return torch.exp(u * math.log(cfg_omega_max))
    power = 1.0 - cfg_beta
    return (1 + u * (cfg_omega_max ** power - 1)) ** (1 / power)

def sample_cfg_interval(bs, full_mask, t_min_range=(0.0, 0.5), t_max_range=(0.5, 1.0)):
    def uniform(low, high):
        return low + (high - low) * torch.rand(bs)
    t_min = torch.where(full_mask, 0.0, uniform(*t_min_range))
    t_max = torch.where(full_mask, 1.0, uniform(*t_max_range))
    return t_min, t_max

def adaptive_loss(error, adaptive_eps=0.01, adaptive_p=1.0):
    loss = error.square().flatten(1).sum(dim=1)
    return loss / (loss.detach() + adaptive_eps).pow(adaptive_p)

def train(z_0):
    # 1. Sample the timesteps r and t.
    r, t = sample_time_steps(bs)

    # 2. Sample the guidance scale and interval.
    omega = sample_cfg_scale(bs)
    t_min, t_max = sample_cfg_interval(bs, r == t)

    # 3. Build the noisy latent z_t and its velocity v_t.
    noise = torch.randn_like(z_0)
    z_t = (1 - t) * z_0 + t * noise  # linear path
    v_t = noise - z_0  # conditional velocity

    # 4. Predict the average velocity u and the instantaneous velocity v with a class dropout.
    dropped = rand(bs) < 0.1  # 10% class dropout
    y_in = where(dropped, null, y)
    u, v = model(z_t, r, t, omega, t_min, t_max, y=y_in)  # Eq. 16

    # 5. Predict the conditional and unconditional instantaneous velocities at t with the v-head.
    omega_t = where((t >= t_min) & (t <= t_max), omega, 1)
    with no_grad():
        v_c, v_u = model(cat([z_t, z_t]), cat([t, t]), cat([t, t]), cat([omega_t, ones]), cat([zeros, zeros]),
                         cat([ones, ones]), y=cat([y, null]), predict_u=False).chunk(2)  # Eq. 17

    # 6. Build the guided velocity target.
    v_target = v_t + (1 - 1 / omega_t) * (v_c - v_u)  # Eq. 17
    v_target = where(dropped, v_t, v_target)

    # 7. Build the compound prediction V, with the predicted v_c as the JVP tangent.
    fn = lambda z, r_, t_: model(z, r_, t_, omega, t_min, t_max, y=y_in, predict_v=False)
    _, dudt = jvp(fn, (z_t, r, t), (v_c, zeros_like(r), ones_like(t)))
    V = u + (t - r) * dudt  # Eq. 15

    # 8. Calculate the loss of the u-head and of the auxiliary v-head.
    loss = adaptive_loss(V - v_target) + adaptive_loss(v - v_target)
    loss = loss.mean()

Predict the clean image rather than the noise, and a plain ViT on raw pixel patches becomes a strong diffusion model at any resolution.
Insight. The prediction target, not the tokenizer, blocked diffusion on raw pixels. Latent-free generation is again a serious route at scale.

  • The manifold assumption (§3.3). Clean data lies near a low-dimensional manifold, but the noise ϵ and the velocity v do not. Thus a network that predicts x needs only the manifold coordinates. A network that predicts ϵ or v must keep all D=768 dimensions of a 16×16 patch.

  • Flow setup (§3.1, Eq. 1–2). zt=tx+(1−t)ϵ Eq. (1) moves noise ϵ to data x at t=1, and v=x−ϵ Eq. (2), with logit(t)~𝒩(−0.8,0.82).

  • x-prediction under the v-loss (§3.2, Eq. 5–6). Under Eq. (1–2), one output gives the others, vθ=(xθ−zt)/(1−t) Eq. (5). So the network predicts the image: ℒ=𝔼‖vθ(zt,t)−v‖2 with vθ(zt,t)=(netθ(zt,t)−zt)/(1−t), where 1−t is clipped at 0.05 to prevent division by zero.

  • Plain ViT on pixels (§4.1–4.2). A ViT takes 16×16 tokens of p×p×3 pixels, and a two-layer bottleneck d′<768 embeds each patch.

  • Sampling (§3.1, Eq. 4). Take 50 Heun steps on a linear t in [0,1], with an Euler last step and guidance only on t∈[0.1,1].

  • Experiments (§5). On ImageNet 256, JiT-H/16 gets FID 1.86 at 182 Gflops (latent DiT-XL/2: 2.27). At 512, JiT-G/32 gets 1.78.

  • 512 beats 256 at scale (Tab. 6). JiT-G/32 at 512 gets 1.78, and JiT-G/16 at 256 gets only 1.82. The paper says it overfits less.

def sample_t(bs, p_mean=-0.8, p_std=0.8):
    return torch.sigmoid(torch.randn(bs) * p_std + p_mean)  # logit-normal

def to_velocity(net, z, t, y, t_eps=0.05):
    return (net(z, t, y) - z) / (1 - t).clamp_min(t_eps)  # Eq. 5, from the x-prediction

def guided_velocity(net, z, t, y, cfg=2.9, interval=(0.1, 1.0)):
    v_c, v_u = to_velocity(net, z, t, y), to_velocity(net, z, t, null)
    scale = cfg if interval[0] < t < interval[1] else 1.0  # guidance interval
    return v_u + scale * (v_c - v_u)

def train(net, x, y, noise_scale=1.0, t_eps=0.05, label_drop_prob=0.1):
    # 1. Sample a time, and sample noise with a scale for the resolution.
    t = sample_t(bs)
    e = torch.randn_like(x) * noise_scale

    # 2. Interpolate, and calculate the target velocity.
    z = t * x + (1 - t) * e  # Eq. 1
    v = (x - z) / (1 - t).clamp_min(t_eps)  # Eq. 2, v = x - e

    # 3. Predict the clean image with a class dropout, and convert it to a velocity.
    y = where(rand(bs) < label_drop_prob, null, y)
    v_pred = to_velocity(net, z, t, y)

    # 4. Calculate the v-loss.
    loss = (v_pred - v).square().mean()  # Eq. 6

def sample(net, y, num_steps=50, noise_scale=1.0):
    z = torch.randn(shape) * noise_scale
    ts = linspace(0, 1, num_steps + 1)
    for i in range(num_steps):
        v = guided_velocity(net, z, ts[i], y)
        if i == num_steps - 1:
            z = z + (ts[i + 1] - ts[i]) * v  # last step Euler
        else:
            v_next = guided_velocity(net, z + (ts[i + 1] - ts[i]) * v, ts[i + 1], y)
            z = z + (ts[i + 1] - ts[i]) * (v + v_next) / 2  # Eq. 4, Heun
    return z

It shows that the MeanFlow loss has two conflicting terms, and it anneals a family of losses from trajectory flow matching to the MeanFlow loss.
Insight. Part of the one-step quality gap is in the optimization, not the objective: the final loss is MeanFlow's, but the samples are better.

  • MeanFlow loss (§2, Eq. 5). The network uθ(zt,r,t) predicts the average velocity over [r,t] from the latent zt=(1−t)x+tϵ for the data x and the noise ϵ. MeanFlow fits ℒMF=𝔼‖uθ−vt+(t−r)duθ−/dt‖22, where vt=ϵ−x, θ− is the stop-gradient copy, and d/dt is one JVP call.

  • Loss decomposition (§3.1, Eq. 6). ℒMF=ℒTFM+ℒTC+C, where ℒTFM=𝔼‖uθ−vt‖22 is trajectory flow matching and ℒTC=𝔼[2(t−r)uθ⊤duθ−/dt] is trajectory consistency. Their gradients have a cosine below −0.4, so joint training is slow and unstable.

  • Two timesteps (§3.2, Tab. 3). t and r<t come from lognorm(−0.4,1.0), and 50% of the pairs on XL/2 set r=t (B/2: 25%, MeanFlow: 75%). The plain flow matching loss ℒFM′ Eq. (7) is ℒTFM on the r=t slice, where ℒTC=0. So it lowers ℒTFM with less gradient conflict with ℒTC.

  • α-Flow loss (Def. 1, Eq. 8). ℒα=𝔼[α−1‖uθ(zt,r,t)−(αv~s,t+(1−α)uθ−(zs,r,s))‖22], where s=αr+(1−α)t and zs=zt−(t−s)v~s,t. α∈(0,1] is the consistency step ratio, the shift velocity is v~s,t=vt, and θ− is not an EMA copy. For α>0, one model call at s replaces the JVP call.

  • Unification (Thm. 1). With v~s,t=vt, α=1 gives ℒTFM. With v~s,t=uθ−(zt,s,t), α=1/2 gives twice the Shortcut loss. As α→0, ∇θℒα→∇θℒMF: expand uθ−(zs,r,s) to first order at s=t. Consistency training (CT) is the case r≡0 with a clean-data prediction.

  • Curriculum (§4.2). Training has three phases: (1) trajectory flow matching at α=1, (2) a transition that lowers α from 1 to 0, (3) MeanFlow fine-tuning at α=0 with the JVP target of Eq. (5). The first phase reaches the narrow ℒTFM manifold before the gradient conflict starts.

  • Schedule (Alg. 2). At iteration k, α=1−sigmoid(γ(k−(ks+ke)/2)/(ke−ks)) with γ=25, ks=600K, ke=1M of the 1.2M training steps on XL/2, where ks and ke are the start and the end of the transition. α is 1 above 1−η and 0 below η=5×10−3, the best fixed α (Tab. 5c).

  • Adaptive weight (§4.2, App. H.2). As α→0, ℒα→αℒMF, so the MeanFlow weight 1/(‖Δ‖22+c) for the error Δ becomes ω=α/(‖Δ‖22+c), c=10−3, with ω under the stop-gradient operator. On the r=t rows and in the MeanFlow phase, the numerator is 1 instead of α.

  • Guidance (§4.2, App. G). As in MeanFlow, v~s,t=wvt+κuθ−(zt,t,t∣c)+(1−w−κ)uθ−(zt,t,t∣∅) for the class c and the null class ∅, with the CFG scales w=0.2, κ=0.92 for t<0.75 on XL/2, with a 10% class dropout. uθ−(zt,t,t) is the model's own instantaneous velocity.

  • Sampling (§4.2, Alg. 3). One step is z0=z1−uθ(z1,0,1). For two steps, XL/2 uses consistency sampling: x^=z−tuθ(z,0,t), then z←(1−t′)x^+t′ϵ at t′=0.55. B/2 uses the ODE step z←z−(t−t′)uθ(z,t′,t). For MeanFlow-XL/2, the ODE step is better (Fig. 5).

  • Experiments (§5). On ImageNet-256, α-Flow-XL/2 gets one-step FID 2.95 (MeanFlow: 3.43) at 240 epochs, and XL/2+ gets 2.58.

  • A JVP-free α-Flow falls short (Tab. 5d). At a fixed α=0.005, FID on B/2 is 45.6, against 43.3 for MeanFlow and its JVP target.

def sample_time_steps(bs, time_mu=-0.4, time_sigma=1.0, ratio_r_equal_t=0.5):
    def logit_normal(n):
        return torch.sigmoid(torch.randn(n) * time_sigma + time_mu)

    n_equal = int(bs * ratio_r_equal_t)
    t_equal = logit_normal(n_equal)  # r = t
    t_1, t_2 = logit_normal(bs - n_equal), logit_normal(bs - n_equal)
    t = cat([t_equal, torch.maximum(t_1, t_2)])
    r = cat([t_equal, torch.minimum(t_1, t_2)])  # make r < t

    return r, t

def sample_alpha(k, k_s=600_000, k_e=1_000_000, gamma=25.0, eta=5e-3):
    scale, offset = 1 / (k_e - k_s), -(k_s + k_e) / 2 / (k_e - k_s)
    alpha = 1 - 1 / (1 + math.exp(-(scale * k + offset) * gamma))  # Alg. 2
    if alpha < eta:
        return 0.0
    return 1.0 if alpha > 1 - eta else alpha

def train(
    model, z_0, y, k,
    cfg_w=0.2, cfg_kappa=0.92, cfg_min_t=0.0, cfg_max_t=0.75, cfg_prob=0.1,
    clamp_target=4.0, adaptive_eps=1e-3
):
    # 1. Sample the timesteps r and t, the ratio alpha and the intermediate timestep s.
    r, t = sample_time_steps(bs)
    alpha = sample_alpha(k)
    s = alpha * r + (1 - alpha) * t

    # 2. Build the noisy latent z_t and its velocity v_t.
    noise = torch.randn_like(z_0)
    z_t = (1 - t) * z_0 + t * noise  # linear path
    v_t = noise - z_0  # conditional velocity

    # 3. Predict the average velocity u with a class dropout.
    guided = (t > cfg_min_t) & (t < cfg_max_t)
    y = torch.where(guided & (rand(bs) < cfg_prob), null, y)
    u = model(z_t, r, t, y)

    # 4. Calculate the guided velocity.
    with no_grad():
        u_c, u_u = model(cat([z_t, z_t]), cat([t, t]), cat([t, t]), y=cat([y, null])).chunk(2)
    v_tilde = cfg_w * v_t + cfg_kappa * u_c + (1 - cfg_w - cfg_kappa) * u_u
    v_tilde = torch.where(guided, v_tilde, v_t)

    # 5. Build the target: the JVP target at alpha = 0, else the alpha-Flow target.
    with no_grad():
        if alpha == 0:
            fn = lambda z, r_, t_: model(z, r_, t_, y)
            _, dudt = jvp(fn, (z_t, r, t), (v_tilde, zeros_like(r), ones_like(t)))
            u_target = v_tilde - (t - r) * dudt  # Eq. 5
        else:
            z_s = z_t - (t - s) * v_tilde  # trajectory value at s
            u_target = alpha * v_tilde + (1 - alpha) * model(z_s, r, s, y)  # Eq. 8
            u_target = torch.where(r == t, v_tilde, u_target.clamp(-clamp_target, clamp_target))

    # 6. Calculate the adaptively weighted prediction error.
    loss = (u - u_target).square().flatten(1).mean(1)
    row_alpha = torch.where(r == t, 1.0, alpha) if alpha > 0 else ones_like(t)
    loss = (row_alpha * loss / (loss.detach() + adaptive_eps)).mean()

def sample(model, z, y, time_steps=(1.0, 0.55, 0.0), consistency=True):
    for t, t_next in zip(time_steps[:-1], time_steps[1:]):
        if consistency:
            x_hat = z - t * model(z, 0.0, t, y=y)
            z = (1 - t_next) * x_hat + t_next * torch.randn_like(z)  # consistency sampling
        else:
            z = z - (t - t_next) * model(z, t_next, t, y=y)  # ODE step
    return z

Model the average velocity over an interval, not the instantaneous one, for a one-step generator from scratch with guidance in the field.
Insight. An identity that the regressed quantity must satisfy replaces the teacher. The identity-plus-JVP template opened one-step training.

  • Average velocity definition (§4.1, Eq. 3). u(zt,r,t)≜(1/(t−r))∫rtv(zτ,τ)dτ: the displacement over [r,t], a field from v alone.

  • The MeanFlow identity (Eq. 6). Differentiate (t−r)u=∫rtv with respect to t to get u(zt,r,t)=v(zt,t)−(t−r)du/dt Eq. (6).

  • JVP (Eq. 8). du/dt=(dzt/dt)∂zu+(dr/dt)∂ru+(dt/dt)∂tu=v∂zu+∂tu is one Jacobian–vector product, with the tangent (v,0,1).

  • The objective (Eq. 9–11). ℒ(θ)=𝔼‖uθ(zt,r,t)−sg(utgt)‖22 with utgt=vt−(t−r)(vt∂zuθ+∂tuθ): stop-gradient avoids double backpropagation.

  • Sampling (§4.1, Eq. 12). zr=zt−(t−r)uθ(zt,r,t): the integral is the prediction, so z0=z1−uθ(z1,0,1) is one call. Few steps chain it.

  • Guidance inside the field (§4.2, Eq. 19). Define vcfg≜ωv(zt,t∣c)+(1−ω)v(zt,t) for the class c, so vtcfg=ωuθ(zt,t,t|c)+(1−ω)uθ(zt,t,t). A mixing scale κ gives another form, v~t≜ω(ϵ−x)+κuθ(zt,t,t∣c)+(1−ω−κ)uθ(zt,t,t), with ω and κ as the two CFG scales.

  • Adaptive loss weighting (§4.3, App. B.2, Tab. 1e). For the error Δ=uθ−utgt, the powered loss ‖Δ‖22γ equals the squared L2 loss under the weight w=1/(‖Δ‖22+c)p, p=1−γ, c=10−3, as sg(w)·‖Δ‖22. FID is 61.06 for p=1, 63.98 for Pseudo-Huber-like p=0.5, 79.75 for plain L2.

  • Two timesteps (§4.3, Tab. 1a/c/d). (r,t) come from lognorm(−0.4,1.0), t>r, and only 25% of pairs keep r≠t. The input is (t,t−r).

  • Experiments (§5). On ImageNet-256 with DiT B/2–XL/2, one-step FID is 3.43 (Shortcut: 10.60). Two steps get 2.20, like a 250-step DiT.

def sample_bootstrap_steps(n, denoise_timesteps=128):
    log2_sections = int(log2(denoise_timesteps))
    dt_base = (log2_sections - 1 - torch.arange(log2_sections)).repeat_interleave(n // log2_sections)
    dt_base = cat([dt_base, zeros(n - len(dt_base))])  # exponents 6, ..., 0, the remainder at d = 1
    t = torch.floor(torch.rand(n) * 2 ** dt_base) / 2 ** dt_base  # t on multiples of d
    return t, dt_base

def train(model, model_ema, x_1, y, bootstrap_every=8, denoise_timesteps=128, class_dropout_prob=0.1):
    # 1. Sample step sizes and times for the bootstrap rows.
    n_b = bs // bootstrap_every
    t_b, dt_base = sample_bootstrap_steps(n_b)
    d = 1 / 2 ** dt_base

    # 2. Build the bootstrap targets from two chained half-steps of the EMA model.
    x_0 = torch.randn_like(x_1)
    x_t_b = (1 - (1 - 1e-5) * t_b) * x_0[:n_b] + t_b * x_1[:n_b]  # Eq. 1, a 1e-5 noise floor
    with no_grad():
        s_1 = model_ema(x_t_b, t_b, dt_base + 1, y[:n_b])  # dt_base + 1 is the step d/2
        x_mid = clip(x_t_b + d / 2 * s_1, -4, 4)  # Eq. 3
        s_2 = model_ema(x_mid, t_b + d / 2, dt_base + 1, y[:n_b])
        s_target = clip((s_1 + s_2) / 2, -4, 4)  # Eq. 4

    # 3. Build the flow-matching targets for the other rows on the finest grid, with a class dropout.
    t_f = torch.randint(0, denoise_timesteps, (bs - n_b,)) / denoise_timesteps
    x_t_f = (1 - (1 - 1e-5) * t_f) * x_0[n_b:] + t_f * x_1[n_b:]
    v_target = x_1[n_b:] - (1 - 1e-5) * x_0[n_b:]  # Eq. 1
    y_f = where(rand(bs - n_b) < class_dropout_prob, null, y[n_b:])

    # 4. Regress both kinds of target with one loss.
    dt_flow = full((bs - n_b,), log2(denoise_timesteps))  # flow rows use the finest step
    x_t, t, dt_in = cat([x_t_b, x_t_f]), cat([t_b, t_f]), cat([dt_base, dt_flow])
    loss = (model(x_t, t, dt_in, cat([y[:n_b], y_f])) - cat([s_target, v_target])).square().mean()  # Eq. 5

def sample(model, y, num_steps=1, cfg_scale=4.0):
    x = torch.randn(shape)
    dt_base = full((bs,), log2(num_steps))
    for i in range(num_steps):
        t = full((bs,), i / num_steps)
        s_c, s_u = model(x, t, dt_base, y), model(x, t, dt_base, null)
        x = x + (s_u + cfg_scale * (s_c - s_u)) / num_steps  # Eq. 3
    return x

def sample_time(bs, p_mean=-0.8, p_std=1.6, sigma_d=0.5):
    tau = torch.randn(bs) * p_std + p_mean
    return torch.arctan(torch.exp(tau) / sigma_d)  # log-normal proposal on sigma_d tan(t)

def train(
    model, weight_net, teacher, x_0, iters, consistency_training=False,
    sigma_d=0.5, c=0.1, warmup_iters=10000, cfg_max=2.0
):
    # 1. Sample t and build the TrigFlow sample x_t.
    t = sample_time(bs)
    z = torch.randn_like(x_0) * sigma_d
    x_t = cos(t) * x_0 + sin(t) * z

    # 2. Get the ODE direction from the pair for sCT, or from the guided teacher for sCD.
    s = rand(bs) * (cfg_max - 1) + 1  # guidance scale, also a student input
    if consistency_training:
        dxdt = cos(t) * z - sin(t) * x_0
    else:
        dxdt = sigma_d * teacher(x_t / sigma_d, t, s)  # Eq. 3

    # 3. Run the student, and run its stop-gradient copy through the rearranged JVP.
    F = model(x_t / sigma_d, t, s)
    tangent = (cos(t) * sin(t) * dxdt, cos(t) * sin(t) * sigma_d)
    with no_grad():
        F_sg, cs_dFdt = jvp(lambda x, t_: model(x, t_, s), (x_t / sigma_d, t), tangent)

    # 4. Build the warmed-up tangent and normalize it.
    r = min(1.0, iters / warmup_iters)
    g = -cos(t) ** 2 * (sigma_d * F_sg - dxdt) - r * (cos(t) * sin(t) * x_t + cs_dFdt)  # Eq. 6 times cos(t)
    g = g / (g.flatten(1).norm(dim=1) + c)

    # 5. Calculate the adaptive-weighted loss.
    w, D = weight_net(t), x_0[0].numel()
    loss = (exp(w) / D * (F - F_sg - g).square().flatten(1).sum(1) - w).mean()  # Eq. 8

def noise_pyramid(noise, stages=3):
    pyramid = [noise]
    for _ in range(stages - 1):
        pyramid.append(2 * interpolate(pyramid[-1], scale_factor=0.5, mode="bilinear"))  # 2x keeps unit variance
    return pyramid[::-1]  # coarse to fine

def stage_sigmas(stages=3, stage_range=(0, 1 / 3, 2 / 3, 1), gamma=1 / 3):
    start, end = [], []
    for k in range(stages):
        s = 1 - stage_range[k]  # noise level where stage k starts on the global schedule
        if k > 0:
            signal = 1 - s
            s = 1 - signal / (sqrt(1 + 1 / gamma) * (1 - signal) + signal)  # corrected so Eq. 15 holds
        start.append(s)
        end.append(1 - stage_range[k + 1])
    dist = [s - e for s, e in zip(start, end)]
    bounds = [sum(dist[:k]) / sum(dist) for k in range(stages + 1)]  # each stage's share of the timestep axis
    return start, end, bounds

def stage_timestep(r, k, bounds, num_train_timesteps=1000):
    return num_train_timesteps * (1 - bounds[k] - (1 - r) * (bounds[k + 1] - bounds[k]))

def history_condition(latents, k, num_units, frame_per_unit=1, corrupt_ratio=1 / 3):
    sigma = torch.rand(bs) * corrupt_ratio  # t' ~ U[0, 1/3]
    corrupt = lambda clip: sigma * torch.randn_like(clip) + (1 - sigma) * clip
    hist, j, stage = [], 1, k
    while j < num_units and (j == 1 or stage > 0):  # j units back, one stage coarser each
        hist.append(corrupt(latents[stage][:, :, -(j + 1) * frame_per_unit:-j * frame_per_unit]))  # Eq. 16
        j, stage = j + 1, max(stage - 1, 0)
    if j < num_units:
        hist.append(corrupt(latents[0][:, :, :-j * frame_per_unit]))  # the rest at the coarsest stage
    return hist[::-1]

def past_condition(history, k):
    scales = [0.5 ** (2 - max(k - j, 0)) for j in range(len(history))]
    return [interpolate(h, scale_factor=s) for h, s in zip(history[::-1], scales)][::-1]  # Eq. 17

def block_noise(x, gamma=1 / 3):
    cov = torch.eye(4) * (1 + gamma) - torch.ones(4, 4) * gamma  # Sigma' of Eq. 14, per 2x2 block
    n = MultivariateNormal(torch.zeros(4), cov).sample(x.shape[:-2] + (x.shape[-2] // 2, x.shape[-1] // 2))
    return rearrange(n, "... h w (p q) -> ... (h p) (w q)", p=2, q=2)

def train(model, latents, text, num_units, sample_ratios=(1.0, 2.0, 1.0), frame_per_unit=1):
    # 1. Build the noise pyramid from one Gaussian noise. The list latents holds the clip at each stage's resolution.
    noise = noise_pyramid(torch.randn_like(latents[-1]))
    start_sigma, end_sigma, bounds = stage_sigmas()

    # 2. Pick a stage and build its endpoints from the shared noise.
    k = torch.multinomial(torch.tensor(sample_ratios), 1).item()
    coarse = interpolate(latents[k - 1], scale_factor=2, mode="nearest") if k > 0 else 0
    start = start_sigma[k] * noise[k] + (1 - start_sigma[k]) * coarse  # Eq. 10, pure noise at k = 0
    end = end_sigma[k] * noise[k] + (1 - end_sigma[k]) * latents[k]  # Eq. 9, the clean latent at k = 2

    # 3. Interpolate inside the stage and map the position to the model's timestep.
    r = torch.rand(bs)  # 1 at the stage's start, 0 at its end
    x_t = r * start + (1 - r) * end  # Eq. 6
    t = stage_timestep(r, k, bounds)

    # 4. Keep the newest unit as the trained one and condition it on the corrupted history.
    x_t, target = x_t[:, :, -frame_per_unit:], (start - end)[:, :, -frame_per_unit:]
    hist = history_condition(latents, k, num_units)
    text = where(rand(bs) < 0.1, "", text)  # 10% text dropout

    # 5. Regress the stage displacement on the newest unit.
    v = model(cat(hist + [x_t], dim=2), t, text)[:, :, -frame_per_unit:]  # blockwise causal attention
    loss = (v - target).square().mean()  # Eq. 11

def sample(
    model, text, num_units,
    steps=(20, 20, 20), video_steps=(10, 10, 10), guidance=7.0, video_guidance=5.0
):
    start_sigma, _, bounds = stage_sigmas()
    history = []
    for unit in range(num_units):
        x = torch.randn(low_res_shape)  # stage 0 starts from noise at the coarsest resolution
        n_steps, scale = (steps, guidance) if unit == 0 else (video_steps, video_guidance)
        for k in range(3):
            if k > 0:
                s_k = 1 - start_sigma[k]  # the stage's corrected start signal
                up = interpolate(x, scale_factor=2, mode="nearest")
                x = (1 + s_k) / 2 * up + sqrt(3) * (1 - s_k) / 2 * block_noise(up)  # Eq. 15
            rs = linspace(1, 0, n_steps[k] + 1)
            for r, r_next in zip(rs[:-1], rs[1:]):
                inp, t = cat(past_condition(history, k) + [x], dim=2), stage_timestep(r, k, bounds)
                v_c, v_u = model(inp, t, text)[:, :, -1:], model(inp, t, "")[:, :, -1:]
                x = x + (r_next - r) * (v_u + scale * (v_c - v_u))  # Euler step
        history.append(x)
    return cat(history, dim=2)

  • Neural jump (§3.1, §5.1). Gθ=(s/t)xt+(1−s/t)gθ with gθ(xt,t,s)=cskip(t)xt+cout(t)NNθ(xt,t,s), EDM's scalings, and a time embedding for s. So Gθ(xt,t,t)=xt needs no extra constraint. The teacher's weights start gθ(xt,t,t) near Dϕ, so training is 10–20 times faster.

  • Soft consistency (§3.2, Eq. 3). The teacher solves from t to u∈[s,t), then the student jumps to s: Gθ(xt,t,s)≈Gsg(θ)(Solver(xt,t,u;ϕ),u,s). sg(θ) is the stop-gradient EMA of θ with μ=0.999. With u=t−Δt and s=0, it is the distillation target of consistency models (CM).

  • CTM loss (§3.2). The EMA student takes both sides of Eq. (3) to time 0: xest=Gsg(θ)(Gθ(xt,t,s),s,0) and xtarget=Gsg(θ)(Gsg(θ)(Solver(xt,t,u;ϕ),u,s),s,0). Then ℒCTM=𝔼[d(xtarget,xest)], where d is LPIPS, a feature distance on clean images.

  • Timesteps (App. D.1). t>u≥s lie on an EDM grid with N=40. The teacher takes k Heun steps from t to u, with k≤20 and p(k)∝k.

  • DSM loss (§3.3). ℒDSM=𝔼‖x0−gθ(xt,t,t)‖22 trains the denoiser at s=t, where the factor 1−s/t gives gθ almost no gradient. Half of the times come from lognormal(−1.2,1.2), and half come from the high noise of the grid, so the network keeps a good denoiser at large t.

  • GAN loss (§3.3). A discriminator dη compares the generated and the real images by ℒGAN=𝔼[logdη(x0)]+𝔼[log(1−dη(xest))]. The code uses a hinge loss on eight StyleGAN-XL heads over EfficientNet and DeiT features. The GAN loss joins after 10K warm-up steps without it.

  • Adaptive weights (§3.3). λDSM=‖∇θLℒCTM‖/‖∇θLℒDSM‖, and λGAN has the same form, where θL is the last layer. They balance the gradient scales of the losses, and the objective is minθmaxηℒCTM+λDSMℒDSM+λGANℒGAN. The released code clips λGAN to [0.01,10].

  • γ-sampling (§4, Alg. 2). Each step jumps from tn to t~n+1=1−γ2tn+1 and adds the noise γtn+1ϵ. γ=1 is the CM sampler: all jumps end at time 0, so their errors add up (Thm. 1). γ=0 is deterministic and adds no noise, and 0<γ<1 generalizes the stochastic sampler of EDM.

  • Experiments (§5). On CIFAR-10 and ImageNet-64, one-step FID is 1.98 and 1.92. EDM needs 35 and 79 steps for 2.01 and 2.44.

  • No teacher is necessary (§5.2). With gθ(xt,t,t) as its own teacher, one-step CIFAR-10 FID is 2.39 (consistency training: 8.70).

  • Recall is lower (Tab. 2). On ImageNet-64, recall is 0.57 (EDM: 0.67, CM: 0.63), but the paper says that the samples look diverse.

def karras_t(ramp, sigma_min=0.002, sigma_max=80.0, rho=7.0):
    return (sigma_max ** (1 / rho) + ramp * (sigma_min ** (1 / rho) - sigma_max ** (1 / rho))) ** rho

def sample_indices(bs, num_scales=40, max_heun_steps=20):
    p = torch.arange(1, max_heun_steps + 1).float()  # p(k) proportional to k
    k = torch.multinomial(p / p.sum(), 1).item() + 1  # one teacher step count per batch
    n_t = torch.randint(0, num_scales - k, (bs,))
    n_u = n_t + k
    n_s = n_u + (torch.rand(bs) * (num_scales - n_u)).long()  # s uniform on the grid below u
    return n_t, n_u, n_s, k

def sample_dsm_sigmas(bs, p_mean=-1.2, p_std=1.2, ramp_max=0.7):
    sigma_lognormal = torch.exp(p_mean + p_std * torch.randn(bs // 2))
    sigma_high = karras_t(torch.rand(bs - bs // 2) * ramp_max)  # high noise of the grid
    return torch.cat([sigma_lognormal, sigma_high])

def jump(net, x_t, t, s, sigma_data=0.5):
    c_in = 1 / (t ** 2 + sigma_data ** 2) ** 0.5
    c_skip = sigma_data ** 2 / (t ** 2 + sigma_data ** 2)
    c_out = t * sigma_data / (t ** 2 + sigma_data ** 2) ** 0.5
    g = c_skip * x_t + c_out * net(c_in * x_t, 250 * log(t), 250 * log(s))  # EDM scalings
    return g, s / t * x_t + (1 - s / t) * g  # g and the neural jump G

def heun_solve(teacher, x, n_t, k, num_scales=40):
    for i in range(k):
        t = karras_t((n_t + i) / (num_scales - 1))
        t_next = karras_t((n_t + i + 1) / (num_scales - 1))
        d = (x - teacher(x, t)) / t  # Eq. 1
        x_euler = x + (t_next - t) * d
        d_next = (x_euler - teacher(x_euler, t_next)) / t_next  # Eq. 1
        x = x + (t_next - t) * (d + d_next) / 2
    return x

def adaptive_weight(loss_ctm, loss_other, last_layer):
    grad_ctm = torch.autograd.grad(loss_ctm, last_layer, retain_graph=True)[0]
    grad_other = torch.autograd.grad(loss_other, last_layer, retain_graph=True)[0]
    return (grad_ctm.norm() / (grad_other.norm() + 1e-4)).clamp(0, 1e4).detach()  # lambda of §3.3

def train(
    net, net_ema, teacher, disc, x_0, last_layer, step,
    num_scales=40, sigma_min=0.002, sigma_data=0.5, mu=0.999, gan_start=10000
):
    # 1. Sample the times t > u >= s on the grid.
    n_t, n_u, n_s, k = sample_indices(bs)
    t, u, s = (karras_t(n / (num_scales - 1)) for n in (n_t, n_u, n_s))

    # 2. Add noise to the data at time t.
    noise = torch.randn_like(x_0)
    x_t = x_0 + t * noise

    # 3. Jump from t to s with the student, and then to time 0 with the EMA student.
    _, G_ts = jump(net, x_t, t, s)
    x_est = jump(net_ema, G_ts, s, sigma_min)[1]

    # 4. Solve the teacher ODE from t to u, jump to s, and then jump to time 0.
    with no_grad():
        x_u = heun_solve(teacher, x_t, n_t, k)
        x_target = jump(net_ema, jump(net, x_u, u, s)[1], s, sigma_min)[1]  # Eq. 3
    loss_ctm = lpips(resize(x_est, 224), resize(x_target, 224)).mean()

    # 5. Calculate the DSM loss of g at s = t.
    sigma = sample_dsm_sigmas(bs)
    g, _ = jump(net, x_0 + sigma * torch.randn_like(x_0), sigma, sigma)
    weight = (sigma ** 2 + sigma_data ** 2) / (sigma * sigma_data) ** 2  # EDM weighting
    loss_dsm = (weight * (g - x_0).square()).flatten(1).mean(1).mean()
    loss = loss_ctm + adaptive_weight(loss_ctm, loss_dsm, last_layer) * loss_dsm

    # 6. Add the GAN loss of a two-jump sample after the warm-up.
    if step >= gan_start:
        x_fake = jump(net, G_ts, s, sigma_min)[1]
        loss_gan = -torch.stack([logit.mean() for logit in disc(x_fake)]).mean()
        loss = loss + adaptive_weight(loss_ctm, loss_gan, last_layer).clip(0.01, 10) * loss_gan

    # 7. Update the EMA student.
    net_ema = mu * net_ema + (1 - mu) * net  # stop-gradient EMA

def train_disc(disc, x_0, x_fake):
    loss_real = torch.stack([torch.relu(1 - logit).mean() for logit in disc(x_0)]).mean()  # hinge loss
    loss_fake = torch.stack([torch.relu(1 + logit).mean() for logit in disc(x_fake.detach())]).mean()
    loss = loss_real + loss_fake

def karras_sigmas(n, num_scales, sigma_min=0.002, sigma_max=80.0, rho=7.0):
    return (sigma_max ** (1 / rho) + n / (num_scales - 1) * (sigma_min ** (1 / rho) - sigma_max ** (1 / rho))) ** rho

def ct_schedule(step, total_steps=800000, start_ema=0.95, start_scales=2, end_scales=200):
    scales = ceil(sqrt(step / total_steps * ((end_scales + 1) ** 2 - start_scales ** 2) + start_scales ** 2) - 1)
    scales = max(scales, 1)
    mu = exp(start_scales * log(start_ema) / scales)  # EMA rate rises with N
    return scales + 1, mu

def f(net, x_t, sigma, sigma_min=0.002, sigma_data=0.5):
    c_skip = sigma_data ** 2 / ((sigma - sigma_min) ** 2 + sigma_data ** 2)
    c_out = (sigma - sigma_min) * sigma_data / (sigma ** 2 + sigma_data ** 2) ** 0.5
    c_in = 1 / (sigma ** 2 + sigma_data ** 2) ** 0.5
    return c_skip * x_t + c_out * net(c_in * x_t, 250 * log(sigma))  # Eq. 5, c_skip = 1 and c_out = 0 at sigma_min

def train(theta, theta_ema, teacher, x, step, distill=True, num_scales=40, mu=0.95):
    # 1. Set N and the EMA rate. Consistency training increases both on a schedule.
    if not distill:
        num_scales, mu = ct_schedule(step)

    # 2. Pick adjacent levels t > t2 of the N-level grid, and add noise to the image at level t.
    n = torch.randint(0, num_scales - 1, (bs,))
    t, t2 = karras_sigmas(n, num_scales), karras_sigmas(n + 1, num_scales)
    noise = torch.randn_like(x)
    x_t = x + t * noise

    # 3. Map x_t with the student.
    pred = f(theta, x_t, t)  # dropout RNG state saved here

    # 4. Take one ODE step to t2 and map it with the EMA target.
    with no_grad():
        if distill:
            d = (x_t - teacher(x_t, t)) / t
            x_t2 = x_t + (t2 - t) * d
            d2 = (x_t2 - teacher(x_t2, t2)) / t2
            x_t2 = x_t + (t2 - t) * (d + d2) / 2  # Eq. 6, Heun on the teacher
        else:
            x_t2 = x + t2 * noise  # Euler on the score estimate lands here
        target = f(theta_ema, x_t2, t2)  # rerun under the student's dropout mask

    # 5. Match the two outputs, then update the EMA target.
    loss = lpips(resize(pred, 224), resize(target, 224)).mean()  # Eq. 7, or Eq. 10 for CT
    theta_ema = mu * theta_ema + (1 - mu) * theta  # Eq. 8

  • Step discretization (§3, Eq. 5). σi<N=(σmax1/ρ+iN−1(σmin1/ρ−σmax1/ρ))ρ with σmin=0.002, σmax=80, ρ=7: steps are shorter near σmin.

  • Stochastic sampler (§4, Alg. 2). Before each step, add new noise, scaled by Snoise slightly above 1, to raise the level to t^i=ti+γiti with γi=min(Schurn/N,2−1) inside [Stmin,Stmax]. Then take a Heun step. The noise corrects earlier errors, and Schurn=0 gives Alg. 1.

  • Preconditioning (§5, Eq. 7–8). The denoiser is Dθ(x;σ)=cskipx+coutFθ(cinx;cnoise) Eq. (7) with the network Fθ, so the loss Eq. (8) regresses (y−cskipx)/cout. cin,cout give unit variance, cskip=σdata2/(σ2+σdata2) minimizes cout to limit the network error, and cnoise=ln(σ)/4.

  • Weighting and noise levels (§5). λ(σ)=1/cout2=(σ2+σdata2)/(σσdata)2 gives unit initial loss. lnσ~𝒩(−1.2,1.22) aims where loss falls.

  • Non-leaking augmentation (§5). Augmentation parameters condition Fθ and are zero at sampling, so augmentations do not leak.

  • Experiments (§3, §5). On CIFAR-10 and ImageNet-64, the sampler takes ImageNet FID 2.07 → 1.55, and retraining gets 1.36.

  • Better models need less churn (Fig. 5). On CIFAR-10, churn helps old models and hurts retrained ones. ImageNet-64 still needs it.

The training and sampling code. Follow Algorithm 1 and 2 of the paper.

def karras_sigmas(num_steps=18, sigma_min=0.002, sigma_max=80, rho=7):
    i = torch.arange(num_steps)
    lo, hi = sigma_min ** (1 / rho), sigma_max ** (1 / rho)
    t = (hi + i / (num_steps - 1) * (lo - hi)) ** rho  # Eq. 5
    return cat([t, zeros(1)])  # t_N = 0

def denoise(model, x, sigma, label, aug=None, sigma_data=0.5):
    c_skip = sigma_data ** 2 / (sigma ** 2 + sigma_data ** 2)
    c_out = sigma * sigma_data / (sigma ** 2 + sigma_data ** 2).sqrt()
    c_in = 1 / (sigma ** 2 + sigma_data ** 2).sqrt()
    return c_skip * x + c_out * model(c_in * x, sigma.log() / 4, label, aug)  # Eq. 7

def train(model, x, label, p_mean=-1.2, p_std=1.2, sigma_data=0.5):
    # 1. Draw one noise level per image from the log-normal distribution.
    sigma = (torch.randn(bs) * p_std + p_mean).exp()

    # 2. Add noise to an augmented image. Its augmentation parameters condition the network.
    y, aug = augment(x)  # aug is zero at sampling time
    x_t = y + torch.randn_like(y) * sigma

    # 3. Denoise through the preconditioning and weight the error by 1 / c_out^2.
    weight = (sigma ** 2 + sigma_data ** 2) / (sigma * sigma_data) ** 2
    loss = (weight * (denoise(model, x_t, sigma, label, aug) - y) ** 2).mean()  # Eq. 8

def sample(model, label, num_steps=18, s_churn=0, s_tmin=0, s_tmax=float("inf"), s_noise=1):
    t = karras_sigmas(num_steps)
    x = torch.randn(shape) * t[0]
    for i in range(num_steps):
        gamma = min(s_churn / num_steps, sqrt(2) - 1) if s_tmin <= t[i] <= s_tmax else 0  # Alg. 2, 0 gives Alg. 1
        t_hat = t[i] * (1 + gamma)
        x_hat = x + (t_hat ** 2 - t[i] ** 2).sqrt() * s_noise * torch.randn_like(x)
        d = (x_hat - denoise(model, x_hat, t_hat, label)) / t_hat  # Eq. 4 with sigma(t) = t
        x = x_hat + (t[i + 1] - t_hat) * d  # Euler step
        if i < num_steps - 1:
            d_next = (x - denoise(model, x, t[i + 1], label)) / t[i + 1]
            x = x_hat + (t[i + 1] - t_hat) * (d + d_next) / 2  # Heun correction
    return x
