Recast MeanFlow's self-written target as plain velocity regression, and turn its frozen guidance scale into one more test-time condition.
Insight. Check what a self-written target really regresses: the tangent carried the conditional velocity it should never see; network-only tangents, and the guidance scale and interval as inputs, make fastforward models cleaner, more flexible and better at one step, 1.72 FID at XL size.

  • What MeanFlow regresses (§3, Eq. 4–7). MeanFlow identity u=v−(t−r)du/dt (Eq. 4), with du/dt=v∂zu+∂tu≜JVP(u;v) (Eq. 5), makes u trainable: target utgt=(e−x)−(t−r)JVP(uθ;e−x) (Eq. 6) is fitted by 𝔼‖uθ−sg(utgt)‖2 (Eq. 7) — e−x standing for v in both places.

  • The identity read backwards (§4.1, Eq. 8–10). Solve for v(zt)=u(zt)+(t−r)du/dt (Eq. 8), make it as Vθ≜uθ+(t−r)JVPsg(uθ;e−x) (Eq. 9) and minimize 𝔼‖Vθ−(e−x)‖2 (Eq. 10) — fully equivalent to Eq. 6–7, and now a v-loss re-parameterized by u-pred.

  • The input that should not be there (Eq. 11, Fig. 1a). Written out, that compound function is Vθ(zt,e−x), reading the conditional velocity as a second argument — illegitimate for a regressor of zt, and traceable to Eq. 6, which put the conditional where Eq. 5 asks for the marginal.

  • Predict the tangent instead (Eq. 12). Vθ(zt)≜uθ(zt)+(t−r)JVPsg(uθ;vθ) (Eq. 12) — both arguments are now network outputs of zt alone. Stop-gradient survives, but inside the prediction rather than on the target, kept because dropping it brings second-order gradients in θ.

  • Two cheap vθ (§4.1, Tab. 1a). The boundary condition vθ(zt,t)≡uθ(zt,t,t) is free — FID 32.69 → 29.42 unguided, 3.43 → 2.99 on XL/2. An auxiliary v-head over the last 8 layers, on its own flow-matching loss, free at inference, does worse unguided, 30.76, better guided, 5.68.

  • Why the conditional tangent hurts (§4.1, Eq. 2, Fig. 3). Feeding e−x to the loss leaks nothing, since the true regression target is the marginal v(zt)≜𝔼[e−x∣zt]; but as the JVP's tangent its variance is magnified by the Jacobian it multiplies, which the two loss curves separate.

  • Guidance, fixed and unfixed (§4.2, Eq. 13–15). MeanFlow bakes vcfg(zt∣c)=ωv(zt∣c)+(1−ω)v(zt) (Eq. 13) in at one ω fixed before training. iMF makes it an input, Vθ(·∣c,ω)≜uθ(zt∣c,ω)+(t−r)JVPsg (Eq. 15), with ω~p(ω)∝ω−β drawn on [1,8], skewed to small ω.

  • The target it fits (App. A, Eq. 17). vtgt=(e−x)+(1−1/ω)(uθ(zt∣t,t,c)−uθ(zt∣t,t,∅)) (Eq. 17) is MeanFlow's guided target with ω an input, so ω=1 means no guidance. FID 5.68 → 5.52, small only because MeanFlow's fixed ω already suited the B/2 model.

  • The interval is a condition too (§4.2, Tab. 1b). Pass Ω={ω,tmin,tmax}, sampling tmin~U[0,0.5] and tmax~U[0.5,1] and switching guidance off (ω=1) when t falls outside — 5.52 → 4.57, while the ω=1 column itself improves 30.76 → 20.95, so training across scales generalizes.

  • In-context conditioning (§4.3, Eq. 16, Tab. 1c). uθ=uθ(zt∣r,t,c,Ω) (Eq. 16) is too heterogeneous for one adaLN-zero to sum; replicate each into tokens — 8 for the class, 4 for the rest — concatenated with the image patches: 4.57 → 4.09, and 133M → 89M once adaLN is gone.

  • Experiments (§5). ImageNet-256 in the VAE latent, from scratch, 1-NFE FID-50K on MeanFlow's code and B/2 baseline: the changes step 6.17 → 5.68 → 4.57 → 4.09, SwiGLU, RMSNorm and RoPE 3.82, 640 epochs 3.39 at 89M; iMF-XL/2 takes 1.72 at 1-NFE and 1.54 at 2-NFE.

  • The size labels do not calibrate (§5.2, Tab. 2). Without adaLN-zero, parameters go to depth: iMF-XL/2 has 48 layers, 610M and 174.6 Gflops to MF-XL/2's 28, 676M and 119.0, so 1.72 against 3.43 is not at matched FLOPs; iMF-M/2's 2.27 at 49.9 Gflops over MF's 5.01 at 54.0 is.

def train():
  # 1. Sample timesteps r and t from lognorm(-0.4, 1.0), sorted so r <= t; 50% of rows get r = t
  r, t = sample_time_steps(bs)

  # 2. Sample the guidance scale and interval; rows with r = t get the full interval [0, 1]
  omega = sample_cfg_scale(bs)  # omega ~ omega^-beta on [1, 8]; assume beta=1
  t_min, t_max = sample_cfg_interval(bs, r == t)  # t_min ~ U[0, 0.5], t_max ~ U[0.5, 1]

  # 3. Build the noisy latent z_t and its velocity v_t
  z_t = (1 - t) * z_0 + t * noise  # linear path
  v_t = noise - z_0  # conditional velocity

  # 4. Predict the average velocity u and the instantaneous velocity v with a class dropout
  dropped = rand(bs) < 0.1  # 10% class dropout
  y_in = where(dropped, null, y)
  u, v = model(z_t, r, t, omega, t_min, t_max, y=y_in)  # Eq. (16); omega and the interval are inputs

  # 5. Predict cond and uncond instantaneous velocity at t with the v head; omega = 1 outside the interval
  omega_t = where((t >= t_min) & (t <= t_max), omega, 1)
  with no_grad():
      v_c, v_u = model(cat([z_t, z_t]), cat([t, t]), cat([t, t]), cat([omega_t, ones]), cat([zeros, zeros]),
                       cat([ones, ones]), y=cat([y, null]), predict_u=False).chunk(2)

  # 6. Build the guided velocity target
  v_target = v_t + (1 - 1 / omega_t) * (v_c - v_u)  # Eq. (17)
  v_target = where(dropped, v_t, v_target)

  # 7. Build the compound prediction V, with the predicted v_c as the JVP tangent
  fn = lambda z, r_, t_: model(z, r_, t_, omega, t_min, t_max, y=y_in, predict_v=False)
  _, dudt = jvp(fn, (z_t, r, t), (v_c, zeros_like(r), ones_like(t)))  # no_grad, so dudt is sg(du/dt)
  V = u + (t - r) * dudt  # Eq. (15)

  # 8. Calculate loss of the u head and the auxiliary v head
  loss = adaptive_loss(V - v_target) + adaptive_loss(v - v_target)  # sum of squared error / (sg(.) + 0.01)^1
  loss = loss.mean()

Predict the clean image rather than the noise, and a plain ViT on raw pixel patches becomes a strong diffusion model at any resolution.
Insight. Match what the network must emit to where the data actually lives: a target lying on a low-dimensional manifold can be produced by a network narrower than the space around it, which is what lets a tokenizer-free Transformer run on raw high-dimensional pixels without a VAE.

  • Noise is off-manifold, data is not (§3.3). Data lies near a low-dimensional manifold; ϵ and v do not, carrying the noise. A network asked for x may keep only the manifold coordinates, so width is no obstacle; one asked for ϵ or v must carry D dimensions through its layers.

  • Flow setup (§3.1, Eq. 1–4). zt=tx+(1−t)ϵ Eq. (1) on a linear noise schedule with logit(t)~𝒩(μ,σ2), so that t=1 is data; the velocity is v=x−ϵ Eq. (2); training minimizes 𝔼‖vθ(zt,t)−v‖2 Eq. (3) and sampling solves dzt/dt=vθ(zt,t) Eq. (4) with a 50-step Heun solver.

  • Nine formulations, none equivalent (§3.2, Eq. 5, Tab. 1). Where the loss lives and what the network emits are independent choices: Eq. (1) and Eq. (2) are two constraints, so one output determines the other two — from xθ, ϵθ=(zt−txθ)/(1−t) and vθ=(xθ−zt)/(1−t) Eq. (5). Three loss spaces times three prediction spaces give nine formulations, each a legitimate generator since any output maps back to v.

  • The one they pick (§4.3, Eq. 6). x-prediction under the v-loss: ℒ=𝔼‖vθ(zt,t)−v‖2 with vθ(zt,t)=(netθ(zt,t)−zt)/(1−t) Eq. (6), the denominator clipped at 0.05. The network's output is the denoised image; the velocity is a transform applied after, not a second head.

  • Just image Transformers (§4.1). Plain ViT — p×p×3 patches linearly embedded, blocks with adaLN-Zero for t and class, a linear layer to pixels; no tokenizer, perceptual loss, pre-training. JiT/16, /32, /64 at 256, 512, 1024 keep 16×16 tokens: flat compute, patches to 12,288-d.

  • Only x-prediction survives a wide patch (§4.2, Tab. 2). JiT-B/16 at 256, where a 768-d patch meets a 768-d hidden size: x-prediction gives 8.62–10.45 FID across the three losses, v-prediction 96.53–126.88 and ϵ-prediction 372–395. Shrink the patch to 48-d (JiT-B/4 at 64×64, same sequence length) and all nine land between 3.46 and 6.20 — which is why latent diffusion, with its small input dimension, never met this.

  • Three plausible fixes that are not enough (§4.2, Tab. 3, Eq. 7–8). (1) Reweighting: x-prediction works in all three loss spaces, the others in none. (2) More noise helps only what works: μ 0 → −0.8 takes x-prediction 14.44 → 8.62 while ϵ-prediction sits at 372. (3) EDM preconditioning Eq. (7)–(8) cannot help: cskip≠0 mixes noise back in again; and its 28.94–72.05 beats ϵ/v only because it nears x-prediction as t→0.

  • Width need not match the patch; less can be better (§4.2). Two linear layers through d′<768 in the patch embedding cut FID, 8.62 → 7.35 at d′=64, 9.40 even at d′=16: classical manifold learning — the network told the useful part is low-dimensional, width freed from D.

  • Just advanced Transformers (§4.4, Tab. 4). A task-agnostic architecture inherits language-model engineering: SwiGLU and RMSNorm as the base, RoPE and QK-norm, then 32 in-context class tokens at a middle block — 7.48 → 6.69 → 5.49 on JiT-B/16, 4.37 with a CFG interval.

  • Experiments (§5, Tab. 5–8). ImageNet at 256, 512 and 1024 by FID-50K and IS, sequence length pinned at 16×16. Four sizes at 600 epochs: 3.66 / 2.36 / 1.86 / 1.82 at 256 and 4.02 / 2.53 / 1.94 / 1.78 at 512; JiT-H/16 reaches 1.86 on 182 Gflops against a latent DiT-XL/2's 2.27 on 119, and at 512 JiT-G/32 is 1.78 on 384 Gflops where pixel baselines spend 555–653 — all without tokenizer, perceptual loss or pre-training.

  • The native parameterization fits its own loss worse (App. B.1). With the loss held in v-space, v-prediction converges ~25% higher than x-prediction and ϵ-prediction ~3× higher, unstably: the FIDs are no sampling artifact; the regression is harder, and the ODE accumulates it.

  • At scale the harder resolution is the easier problem (Tab. 6). JiT-G/32 at 512 reaches 1.78 against JiT-G/16's 1.82 at 256, and the gap closes as models grow — the paper reads 512 denoising as the harder task, hence less prone to the overfitting that decides FID here. The bill: the G models need dropout 0.2 and early stopping near 320 epochs, and every entry has CFG scale and EMA decay swept at inference.

Model the average velocity over an interval, not the instantaneous one — a one-step generator from scratch, with guidance in the field.
Insight. Model displacement over an interval rather than instantaneous velocity: a one-step generator falls out of an identity the network must satisfy, trained from scratch with one JVP — the template for self-consistent fastforward models, with classifier-free guidance folded into the field itself.

  • Average velocity (§4.1, Eq. 3). u(zt,r,t)≜(1/(t−r))∫rtv(zτ,τ)dτ — displacement across [r,t], a field induced by v itself and by no network; limr→tu=v, and integral additivity already gives (t−r)u(zt,r,t)=(s−r)u(zs,r,s)+(t−s)u(zt,s,t), consistency with nothing imposed.

  • The MeanFlow identity (Eq. 6). Multiply the definition by t−r and differentiate in t with r fixed; the product rule and the fundamental theorem give u+(t−r)du/dt=v, that is u(zt,r,t)=v(zt,t)−(t−r)du/dt — the intractable integral traded for a local relation between the fields.

  • One JVP computes it (Eq. 8, Tab. 1b). du/dt=(dzt/dt)∂zu+(dr/dt)∂ru+(dt/dt)∂tu=v∂zu+∂tu, since dzt/dt=v, dr/dt=0: a Jacobian–vector product with tangent (v,0,1), one extra pass. Corrupt it and one-step collapses — 61.06 FID against 137.96–329.22.

  • The objective (Eq. 9–11). ℒ(θ)=𝔼‖uθ(zt,r,t)−sg(utgt)‖22 with utgt=vt−(t−r)(vt∂zuθ+∂tuθ): the network's own partials stand in for those of the true u, the conditional vt for the marginal, and stop-gradient removes double backpropagation. Zero loss recovers the identity of Eq. 3.

  • Sampling (§4.1, Eq. 12). zr=zt−(t−r)uθ(zt,r,t) — the integral is the prediction, so z0=z1−uθ(z1,0,1) is one call; few steps chain it.

  • Guidance inside the field (§4.2, Eq. 19). Define vcfg≜ωv(zt,t∣c)+(1−ω)v(zt,t) and average it; since vcfg(zt,t)=v(zt,t)=ucfg(zt,t,t), the unconditional half is the network's own diagonal, v~t=ωvt+(1−ω)uθ(zt,t,t), so guidance stays a single call (ω=3 gives 15.53).

  • Guidance, improved (App. B.1, Eq. 21, Tab. 5). A mixing scale κ lets the class-conditional diagonal into the target as well: v~t≜ω(ϵ−x)+κuθ(zt,t,t∣c)+(1−ω−κ)uθ(zt,t,t); solving it gives Eq. 13's form vcfg(zt,t∣c)=ω′v(zt,t∣c)+(1−ω′)v(zt,t) at the effective scale ω′=ω/(1−κ). At a fixed ω′=2, κ from 0 to 0.9 takes the 1-NFE FID 20.15 → 18.63; the released XL/2 ships ω=1, κ=0.5.

  • Adaptive loss weighting (§4.3, App. B.2, Tab. 1e). For the error Δ=uθ−utgt, the powered loss ‖Δ‖22γ equals the squared L2 loss under the weight w=1/(‖Δ‖22+c)p, p=1−γ, c=10−3, applied as sg(w)·‖Δ‖22: p=1 gives 61.06, Pseudo-Huber-like p=0.5 63.98, plain L2 79.75.

  • Two clocks (§4.3, Tab. 1a/c/d). (r,t) come from lognorm(−0.4,1.0), and t>r, and only 25% of pairs keep r≠t — at 0% the correction vanishes, the loss is exactly flow matching and 1-NFE fails (328.91 against 61.06). The network is fed (t,t−r), best of four embeddings.

  • Experiments (§5). ImageNet-256 in a VAE latent, FID-50K at 1-NFE, plus CIFAR-10: B/2 to XL/2 reads 6.17 / 5.01 / 3.84 / 3.43 at 240 epochs (Shortcut 10.60), 2.20 at 2-NFE trained longer, DiT-XL/2's 2.27 at 250×2; CIFAR-10 2.92 without EDM preconditioning, against iCT's 2.83.

One network, conditioned on step size, jumps any distance along the flow — trained in one run, with no teacher, schedule, or second stage.
Insight. Condition one network on how far it jumps and bootstrap its own targets: one run serves every budget, no teacher or second stage.

  • Why naive one-step fails (§2, Fig. 2). Flow matching learns the average direction over all pairings passing through xt; at t=0 that average points at the dataset mean, so one big Euler step lands there — multimodal data is unreachable in a single step even at the optimum.

  • Condition on the step size (§3, Eq. 3). The shortcut is the normalized jump to the correct next point, xt+d′=xt+s(xt,t,d)d; at d→0 it is the flow itself, so shortcut models generalize flow matching — one model serves every budget from 128 steps to one.

  • Self-consistency instead of a teacher (§3, Eq. 4–5). One step equals two chained halves, s(xt,t,2d)=s(xt,t,d)/2+s(xt+d′,t+d,d)/2: bootstrap targets come from the model itself, while a batch fraction at d=0 regresses flow matching. One run, ~16% extra compute.

  • A binary grid of step sizes (§3.1). 128 base units give eight shortcut lengths d∈(1/128,…,1), each trained against two of the next size down, keeping bootstrap paths short; many-step quality matches the flow baseline, few- and one-step matches two-stage distillation.

  • Experiments (§5). CelebA-HQ-256 and ImageNet-256, every objective retrained on one DiT-B codebase at matched compute, FID-50K at 128 / 4 / 1 steps: 6.9 / 13.8 / 20.5 and 15.5 / 28.3 / 40.3 — past every end-to-end and two-stage method but progressive distillation's one step.

  • Bootstrapping still scales, and drives robots (§5.3–5.5). Unlike Q-learning, one-step FID keeps falling with size (DiT-XL: 10.6, 3.8 at 128 steps), and as a one-step policy on Push-T and Transport it scores 0.87 / 0.80 where a one-step diffusion policy collapses to 0.12 / 0.00.

Simplify consistency models, stabilize the continuous-time limit by taming its tangent, scale to 1.5B: two steps within 10% of the teacher.
Insight. Derivative-based targets train at scale once their tangents are tamed: parameterization, normalization and a JVP through attention.

  • The continuous-time limit (§2.2, Eq. 2). A consistency model fθ(xt,t) maps any trajectory point to its start, fθ(x,0)≡x. Discrete CMs match adjacent times, 𝔼[w(t)d(fθ(xt,t),fθ−(xt−Δt,t−Δt))] Eq. Insight. A flow cannot cross itself: regressing it onto a crossing interpolation rewires the pairing into a cheaper, deterministic one — and repeating it on the model's own output straightens at a guaranteed rate, which is why one-step generation stopped needing a teacher's full trajectory.

  • Regress the line direction (§2.1, Eq. 1). The interpolation Xt=tX1+(1−t)X0 obeys dXt=(X1−X0)dt, non-causal, needing X1. Causalize by fitting minv∫01𝔼‖(X1−X0)−v(Xt,t)‖2dt Eq. (1). Its minimizer is vX(x,t)=𝔼[X1−X0∣Xt=x] Eq. (2), averaging the lines through x at t.

  • Flows cannot cross, interpolations can (§2.1, Thm. 3.3). Two ODE paths cannot pass one point in different directions, so the fitted flow rewires crossings while keeping the density, Law(Zt)=Law(Xt), so (Z0,Z1) is a coupling — causal, Markovian and deterministic.

  • Rectification is a Pareto descent on cost (§2.2, Thm. 3.5). 𝔼[c(Z1−Z0)]≤𝔼[c(X1−X0)] for every convex c: the rewired path is a sum of segments, by the triangle inequality. It targets no particular cost and reaches the OT map only in 1-D, as the monotone coupling.

  • Reflow (§2.1, Alg. 1). Zk+1=RectFlow((Z0k,Z1k)) — simulate the flow, keep its pairs, fit a new flow to them, starting from independence. Each pass lowers cost and straightens; on the toy problem straightness is near zero after one pass while cost creeps down for twenty more.

  • Straightness, with a rate (§2.2, Eq. 3, Thm. 3.7). S(Z)=∫01𝔼‖(Z1−Z0)−Z˙t‖2dt Eq. (3) is zero exactly when one Euler step Z1=Z0+v(Z0,0) is exact, which forces v to solve the inviscid Burgers' equation ∂tv+(∂zv)v=0. Theorem 3.7 bounds mink≤KS(Zk)≤𝔼‖X1−X0‖2/K, so straightening is guaranteed — but each pass refits an estimate of an estimate, and the paper advises against many such passes.

  • Distillation is the other knob (§2.2). Fitting T^(z0)=z0+v(z0,0) to (Z0k,Z1k) is Eq. (1) with t pinned at 0: it copies the existing coupling faithfully, where reflow replaces it with a cheaper one. So distillation is a last step, applied only once the flow is already very nearly straight.

  • Where the field comes from (§2.2, Eq. 4–5). With a conditional density ρ(x0∣x1), the optimal field has the form vX(z,t)=𝔼[X1−z1−tηt(X1,z)] Eq. (4) with ηt the normalized ρ — enough to show it is well defined and Lipschitz for t<1, and that the exact field would just reproduce the training points. A smooth approximator is thus required; the toy figures use a Nadaraya–Watson kernel estimate Eq. (5), not a neural network.

  • Curved paths are the general case, and stay curved (§2.3, Eq. 6–7, Prop. 3.11). Swap the straight interpolation for any differentiable curve and regress v on X˙t Eq. (6): marginals survive, the cost guarantee and the straightening do not. Proposition 3.11 puts every probability-flow ODE and DDIM in this family as Xt=αtX1+βtξ with αt of Eq.   # 1. Draw a pair and a time; the first flow pairs independent noise with independent data
  x_0, x_1 = pairs()  # the k-th reflow feeds back (z_0, z_1) simulated from the (k-1)-th flow

def reflow(n):

  pairs = [(z, sample(z)) for z in randn(n, *shape)]  # (Z_0, Z_1) of the k-th flow

  # 2. Train a fresh flow on those pairs -- distilling instead would pin t = 0 and copy the coupling
  train(pairs)  # Alg. 1, reflow step

It turned a tangle of theory into a table of independent knobs, and its noise parameterization, Heun sampler and preconditioning are still the default vocabulary a diffusion paper states its design in.

A modular design space for diffusion — sampler, schedule, preconditioning and loss weighting become knobs that turn one at a time.
Insight. Separating a method into knobs that each turn alone is itself the contribution: it let a sampler swap alone lift a finished model from 2.07 to 1.55 FID, and it is why later work states its schedule, sampler and preconditioning as explicit settings instead of inheriting them from a predecessor.

  • One framework, knobs that turn alone (§2, Eq. 1–3). The probability-flow ODE dx=−σ˙σ∇xlogp(x;σ)dt Eq. (1) asks only for a score, and a denoiser fit by 𝔼‖D(y+n;σ)−y‖2 Eq. (2) supplies it as (D−x)/σ2 Eq. (3); Table 1 rewrites VP, VE and iDDPM+DDIM as knob settings.

  • The schedule is a free choice (§3, Eq. 4, Fig. 3). A scale s(t) generalizes the ODE Eq. (4); setting σ(t)=t and s(t)=1 collapses it to dx/dt=(x−D(x;t))/t, so one Euler step to t=0 is the denoised image: near-straight paths. VP and VE gain most of their speedup here.

  • Heun instead of Euler (§3, Alg. 1). A second evaluation of D at the step's far end, averaged trapezoidally, cuts the local error from O(h2) to O(h3) for one call more; the last step to σ=0 reverts to Euler to avoid dividing by 0. Adaptive RK45 here costs more than it returns.

  • Steps warped toward the data end (§3, Eq. 5). σi<N=(σmax1/ρ+iN−1(σmin1/ρ−σmax1/ρ))ρ Eq. (5) with σN=0, σmin=0.002, σmax=80. ρ=3 nearly equalizes truncation error per step, yet 5–10 is far better on images and ρ=7 ships — error made near σmin is what costs most.

  • Stochasticity is Langevin bolted on (§4, Eq. 6, Alg. 2). The SDE splits into the ODE plus a Langevin term whose β(t) is the rate old noise is swapped for new Eq. (6): raise it by γi=min(Schurn/N,2−1) inside [Stmin,Stmax], then step down. It repairs error but bleeds detail.

  • Preconditioning from unit variance (§5, Eq. 7–8). Dθ(x;σ)=cskipx+coutFθ(cinx;cnoise) Eq. (7); writing the loss through Fθ Eq. (8) exposes a weight λcout2 and target (y−cskipx)/cout, from which cin,cout follow by demanding unit variance and cskip=σdata2/(σ2+σdata2) by minimizing cout, so network error is amplified least. FID barely moves, except where the old parameterization failed — VE on FFHQ-64, 41.62 → 3.39.

  • Weight and noise distribution (§5, Fig. 5a). λ(σ)=1/cout2 flattens the weight so every level starts at loss 1, and lnσ~𝒩(−1.2,1.22) aims training there — the only place the trained loss has fallen. Together the largest training gain, 2.29 → 2.05 on unconditional CIFAR-10.

  • Non-leaking augmentation (§5). Geometric transforms applied before the noise, their parameters fed to Fθ as conditioning and zeroed at sampling time so an augmented image can never be generated: 2.05 → 1.97 unconditional and 1.88 → 1.79 conditional on CIFAR-10.

  • Experiments (§3, §5, Tab. 2). FID on CIFAR-10, FFHQ-64, AFHQv2-64 and class-conditional ImageNet-64, first by swapping samplers into three finished models, then retraining: the sampler alone cuts steps to within 3% of best FID by 7.3× (VP), 300× (VE) and 3.2× (DDIM) and lifts ImageNet-64 from 2.07 to 1.55; retraining reaches 1.79 / 1.97 on conditional / unconditional CIFAR-10 at 35 NFE and 1.36 on ImageNet.

  • Stochasticity is a crutch the model outgrows (Fig. 5b–c). The CIFAR-10 panels cross: what made the old training work ruins the new, so a sampler test measures the model under it. Harder, more diverse ImageNet wants noise — where churn earns its place, says the paper.

  sigma = exp(randn(bs) * 1.2 - 1.2)  # P_mean = -1.2, P_std = 1.2

  # 2. Corrupt an augmented image; the augmentation parameters ride along as conditioning
  y, aug = augment(x)  # aug is zeroed at sampling time, so augmentations cannot leak
  x_t = y + randn_like(y) * sigma

  # 3. Preconditioned denoiser: unit-variance input, unit-variance target, skip chosen to damp error
  c_skip = 0.25 / (sigma**2 + 0.25)  # sigma_data = 0.5, so sigma_data^2 = 0.25

  loss = ((sigma**2 + 0.25) / (sigma * 0.5)**2 * (D - y)**2).mean()  # Eq. (8)
