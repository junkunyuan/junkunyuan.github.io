Attention & Transformer Variants

Scalable Diffusion Models with Transformers

William Peebles (9,078), Saining Xie (80,338)

UC Berkeley · New York University · Meta AI (FAIR)

International Conference on Computer Vision (ICCV), 2023

Dec 19, 2022      DiT (8,056)      code (8.7K)

It made the plain transformer the standard diffusion backbone in place of the U-Net. Later image and video generators build on its adaLN-conditioned block.

imagediffusionunread

A transformer on latent patches replaces the U-Net of latent diffusion, and adaLN-Zero blocks take in the timestep and the class label.
Insight. Diffusion quality follows the Gflops of a plain transformer, so later image and video generators scale up this same backbone.

  • Latent input (§3.1, §4). DiT works in the latent space of the Stable Diffusion VAE. A 256×256×3 image becomes z of shape 32×32×4, scaled by 0.18215, and the VAE decoder maps the samples back to pixels. The VAE has 84M parameters and stays frozen during training.

  • Patchify (§3.2). Each p×p patch of the I×I×C input (I=32 at 256×256) becomes one token, so there are T=(I/p)2 tokens of width d with fixed sine-cosine position embeddings, for p∈{2,4,8}. Halving p at least quadruples the Gflops but keeps the parameter count.

  • adaLN-Zero block (§3.2). An MLP on c=temb+yemb regresses the shift β, scale γ and gate α: x←x+α1Attn((1+γ1)LN(x)+β1), and the same for the MLP. Its last layer starts at zero, so each block starts as the identity. It gets FID 19.47, against 26.14 for cross-attention.

  • Model sizes (§3.2, Tab. 1). S, B and L follow ViT, and XL adds 28 layers of width 1152. DiT-XL/2 is XL with p=2, at 118.6 Gflops.

  • Output and loss (§3.1, §3.2). A final adaptive layer norm and a zero-initialized linear layer decode each token to p×p×2C: the noise and a learned diagonal covariance Σθ. Lsimple=‖ϵθ(xt)−ϵt‖22 trains the noise, and the full variational bound trains Σθ with the mean frozen.

  • Guidance on three channels (§3.1, App. A). Training drops labels with the probability 0.1, so the model learns the null class ∅. Sampling uses ϵ^θ=ϵθ(xt,∅)+s(ϵθ(xt,c)−ϵθ(xt,∅)) on the first three of four latent channels only, with s=1.5 for the reported best FID.

  • Experiments (§5). On class-conditional ImageNet 256×256, DiT-XL/2 with guidance 1.5 gets FID 2.27 at 118.6 Gflops (LDM-4-G: 3.60).

  • Gflops, not parameters, set FID (Fig. 8). From XL/8 to XL/2, DiT keeps about 675M parameters and cuts FID from 106.41 to 19.47.

  • More steps do not replace size (Fig. 10). XL/2 with 128 steps gets FID-10K 23.7 at 15.2 Tflops, and L/2 with 1,000 steps gets 25.9.

def linear_alphas(num_steps=1000, beta_start=1e-4, beta_end=2e-2):
    return torch.cumprod(1 - torch.linspace(beta_start, beta_end, num_steps), 0)

def modulate(x, shift, scale):
    return x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)

def dit_block(x, c, attn, mlp, norm1, norm2, ada_ln):
    shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = ada_ln(c).chunk(6, dim=1)  # zero-initialized
    x = x + gate_msa.unsqueeze(1) * attn(modulate(norm1(x), shift_msa, scale_msa))  # adaLN-Zero
    x = x + gate_mlp.unsqueeze(1) * mlp(modulate(norm2(x), shift_mlp, scale_mlp))
    return x

def dit(model, z_t, t, y, patch_size=2):
    x = model.patchify(z_t, patch_size) + model.pos_embed  # T = (I / p)^2 tokens with sine-cosine positions
    c = model.t_embed(t) + model.y_embed(y)
    for block in model.blocks:
        x = dit_block(x, c, *block)
    shift, scale = model.final_ada_ln(c).chunk(2, dim=1)
    return model.unpatchify(model.final_linear(modulate(model.final_norm(x), shift, scale)))  # noise and covariance

def train(model, vae, x, y, scale_factor=0.18215, class_dropout=0.1, num_classes=1000):
    # 1. Encode the images to latents.
    with no_grad():
        z_0 = vae.encode(x).latent_dist.sample() * scale_factor

    # 2. Drop labels for classifier-free guidance, and add noise at a random step t.
    y = torch.where(rand(bs) < class_dropout, num_classes, y)  # the null class
    alphas = linear_alphas()
    t = torch.randint(0, 1000, (bs,))
    noise = torch.randn_like(z_0)
    a_t = alphas[t].view(-1, 1, 1, 1)
    z_t = a_t.sqrt() * z_0 + (1 - a_t).sqrt() * noise

    # 3. Predict the noise and the variance. The bound trains the variance through a frozen mean.
    eps, var = dit(model, z_t, t, y).chunk(2, dim=1)
    loss = (eps - noise).square().mean() + vlb(cat([eps.detach(), var], 1), z_0, z_t, t)  # L_simple and L_vlb

def sample(model, vae, y, num_steps=250, cfg_scale=4.0, scale_factor=0.18215, num_classes=1000):
    z = torch.randn(bs, 4, 32, 32)
    for t in respaced_steps(num_steps):  # 250 of the 1,000 DDPM steps

        z = ddpm_step(z, cat([guided, eps_c[:, 3:]], 1), var[:bs], t)  # learned-range variance
    return vae.decode(z / scale_factor)

High-Resolution Image Synthesis with Latent Diffusion Models

Robin Rombach (71,232), Andreas Blattmann (61,374), Dominik Lorenz (39,811), Patrick Esser (42,667), Björn Ommer (40,716)

LMU Munich · Heidelberg University · Runway ML

Conference on Computer Vision and Pattern Recognition (CVPR), 2022

Dec 20, 2021      LDM (28,859)      code (14.2K)

Its split into a reusable autoencoder and a diffusion model on the latents became the standard base design of open text-to-image and text-to-video models.

imagediffusionunread

Diffusion in the latent space of an autoencoder with mild compression, and cross-attention in the U-Net to condition on text or layouts.
Insight. Spend diffusion compute on content, not on imperceptible pixel detail. Later image and video models kept this two-stage split.

  • Perceptual compression (§3.1). An autoencoder maps x∈ℝH×W×3 to z=ℰ(x)∈ℝh×w×c with the factor f=H/h. An L1 and LPIPS reconstruction loss and a patch-based adversarial loss keep the decoded images sharp. It trains once for many diffusion models.

  • Latent regularization (§3.1). KL-reg. adds a VAE-style KL penalty toward a standard normal with the small weight 10−6, and VQ-reg. puts a vector quantization layer into the decoder, as in a VQGAN tokenizer. Both stop the variance of the latent from growing without limit.

  • Latent scale (§4.3.2). The diffusion model sees 0.18215z, the latent divided by its standard deviation. The scale sets the signal-to-noise ratio of the noised latent, and it changes the results. The paper shows the effect on a KL-regularized f=4 model, with and without the rescaling.

  • Latent diffusion objective (§3.2, Eq. 2). LLDM=𝔼ℰ(x),ϵ~𝒩(0,1),t‖ϵ−ϵθ(zt,t)‖22 is the pixel objective Eq. (1) on the noised latent zt, with t uniform in {1,…,T}. The U-Net ϵθ uses mostly 2D convolutions, because the latent keeps its 2D structure, and one pass of 𝒟 decodes a sample.

  • Cross-attention (§3.3). A domain encoder τθ maps the condition y to τθ(y)∈ℝM×dτ. U-Net layer i attends to it with softmax(QKT/d)V, Q=WQ(i)φi(zt), K=WK(i)τθ(y), V=WV(i)τθ(y), where φi(zt) is the flattened feature map of that layer and d is the width of Q and K.

  • Conditional objective (§3.3, Eq. 3). LLDM=𝔼ℰ(x),y,ϵ,t‖ϵ−ϵθ(zt,t,τθ(y))‖22 trains τθ and ϵθ together. For text, τθ is a transformer on BERT tokens, in a 1.45B-parameter model that trains on the LAION-400M data. The model concatenates spatial conditions to zt instead.

  • Experiments (§4). Factors f=4 to 16 balance speed and quality. On ImageNet, LDM-4 with guidance gets FID 3.60 (ADM-G: 4.59).

  • Worse reconstruction, better samples (§4). VQ latents reconstruct slightly worse than KL latents but give better LDM samples.

def make_alphas(num_steps=1000, linear_start=0.00085, linear_end=0.012):
    betas = torch.linspace(linear_start ** 0.5, linear_end ** 0.5, num_steps) ** 2
    return torch.cumprod(1 - betas, 0)  # cumulative product of alpha_t

def cross_attention(x, context, to_q, to_k, to_v, to_out, heads=8):
    q, k, v = (t.unflatten(-1, (heads, -1)).transpose(1, 2) for t in (to_q(x), to_k(context), to_v(context)))
    attn = (q @ k.transpose(-1, -2) / q.shape[-1] ** 0.5).softmax(-1)  # softmax(QK^T / sqrt(d))
    return to_out((attn @ v).transpose(1, 2).flatten(2))

def train_autoencoder(encoder, decoder, discriminator, x, step, kl_weight=1e-6, disc_weight=0.5, disc_start=50001):
    # 1. Encode the images to a diagonal Gaussian, and decode one sample of it.
    mean, logvar = encoder(x).chunk(2, dim=1)
    z = mean + (0.5 * logvar).exp() * torch.randn_like(mean)
    x_rec = decoder(z)

    # 2. Calculate the L1 and LPIPS reconstruction loss and the small KL penalty.
    rec_loss = ((x - x_rec).abs() + lpips(x, x_rec)).sum() / bs
    kl = 0.5 * (mean ** 2 + logvar.exp() - 1 - logvar).sum([1, 2, 3]).mean()
    loss = rec_loss + kl_weight * kl

    # 3. After disc_start steps, add the patch adversarial loss, scaled to the gradient of the reconstruction loss.
    if step >= disc_start:
        g_loss = -discriminator(x_rec).mean()
        d_weight = grad_norm(rec_loss, decoder.last_layer) / (grad_norm(g_loss, decoder.last_layer) + 1e-4)
        loss = loss + disc_weight * d_weight.clamp(0, 1e4).detach() * g_loss

def train(unet, encoder, cond_encoder, x, y, scale_factor=0.18215):
    # 1. Encode the images with the frozen autoencoder, and scale the latents to unit variance.
    with no_grad():
        mean, logvar = encoder(x).chunk(2, dim=1)
        z_0 = scale_factor * (mean + (0.5 * logvar).exp() * torch.randn_like(mean))

    # 2. Add noise at a random step t.
    alphas = make_alphas()
    t = torch.randint(0, 1000, (bs,))
    noise = torch.randn_like(z_0)
    a_t = alphas[t].view(-1, 1, 1, 1)
    z_t = a_t.sqrt() * z_0 + (1 - a_t).sqrt() * noise

    # 3. Predict the noise. The U-Net calls cross_attention to the encoded condition in its transformer blocks.
    loss = (noise - unet(z_t, t, context=cond_encoder(y))).square().mean()  # Eq. 3

def sample(unet, decoder, cond_encoder, y, num_steps=200, guidance_scale=5.0, scale_factor=0.18215):
    alphas = make_alphas()
    steps = torch.arange(0, 1000, 1000 // num_steps) + 1  # uniform DDIM steps
    c, null = cond_encoder(y), cond_encoder([""] * bs)
    z = torch.randn(bs, 4, 32, 32)
    for i in reversed(range(num_steps)):
        a_t = alphas[steps[i]]
        a_prev = alphas[steps[i - 1]] if i > 0 else alphas[0]
        eps_c, eps_u = unet(cat([z, z]), full((2 * bs,), steps[i]), context=cat([c, null])).chunk(2)
        eps = eps_u + guidance_scale * (eps_c - eps_u)  # classifier-free guidance
        x_0 = (z - (1 - a_t).sqrt() * eps) / a_t.sqrt()
        z = a_prev.sqrt() * x_0 + (1 - a_prev).sqrt() * eps  # DDIM step with eta = 0
    return decoder(z / scale_factor)

Generating Diverse High-Fidelity Images with VQ-VAE-2

Ali Razavi (7,212), Aaron van den Oord (48,328), Oriol Vinyals (294,027)

DeepMind

Advances in Neural Information Processing Systems (NeurIPS), 2019

Jun 02, 2019      VQ-VAE-2 (2,551)

imageautoregressiveunread

A two-level hierarchy of VQ-VAE codes, a coarse map for global structure and a fine map for detail, with PixelCNN priors over both maps.
Insight. A likelihood model on compressed codes can match GANs and keep diversity. Later work kept the codes, not the PixelCNN prior.

  • VQ-VAE objective (§2.1, Eq. 2). The encoder output E(x) becomes its nearest codebook vector e Eq. (1), and the loss is ‖x−D(e)‖22+‖sg[E(x)]−e‖22+β‖sg[e]−E(x)‖22, where D is the decoder, sg is the stop-gradient operator and β weights the last term.

  • EMA codebook (§2.1). Moving averages replace the codebook term: Ni←γNi+(1−γ)ni, mi←γmi+(1−γ)∑jE(x)i,j, ei=mi/Ni, with γ=0.99, where ni counts the batch vectors that map to ei. So each code is the running mean of the encoder vectors that map to it.

  • Two-level hierarchy (§3.1). For 256×256 images, the encoder downsamples by 4 to a 64×64 bottom map and by 2 more to a 32×32 top map. The bottom map also takes the decoded top code, so the top map keeps the global structure and the bottom map keeps the local detail.

  • Priors (§3.2). A PixelCNN with self-attention models the top codes, conditioned on the class. A PixelCNN with large conditioning stacks models the bottom codes, conditioned on the class and the top codes, because self-attention at 64×64 resolution needs too much memory.

  • Classifier-based rejection (§3.3). A pretrained ImageNet classifier scores each sample by the probability of its class, and the method drops the samples with the lowest scores. This trades some diversity for quality, and the paper uses it only for metrics, not for the sample figures.

  • Experiments (§5). On ImageNet, a classifier trained on the model's samples gets 54.83% top-1 on real images (BigGAN-deep: 42.65%).

  • FID punishes the compression blur (§5.3.1). The VQ-VAE reconstructions of real images alone get an FID of about 10, not about 2.

The training and sampling code. Follow §2 and §3 of the paper.

def quantize_ema(z_e, vq, decay=0.99, eps=1e-5):
    flat = z_e.reshape(-1, vq["codebook"].shape[1])
    indices = torch.cdist(flat, vq["codebook"]).argmin(1)  # Eq. 1
    z_q = vq["codebook"][indices].reshape(z_e.shape)

    # Move each code to the running mean of the encoder vectors that map to it.
    one_hot = torch.eye(len(vq["codebook"]))[indices]
    vq["size"].mul_(decay).add_(one_hot.sum(0), alpha=1 - decay)  # N_i
    vq["sum"].mul_(decay).add_(one_hot.T @ flat, alpha=1 - decay)  # m_i
    n = vq["size"].sum()
    size = (vq["size"] + eps) / (n + len(vq["codebook"]) * eps) * n  # Laplace smoothing
    vq["codebook"].copy_(vq["sum"] / size[:, None])  # e_i = m_i / N_i

    commitment = (z_q.detach() - z_e).square().mean()
    return z_e + (z_q - z_e).detach(), commitment  # straight-through estimator

def train(enc_bottom, enc_top, dec_top, decoder, vq_top, vq_bottom, x, commitment_cost=0.25):
    # 1. Encode the image to the bottom features at 1/4 size and the top features at 1/8 size.
    h_bottom = enc_bottom(x)
    h_top = enc_top(h_bottom)

    # 2. Quantize the top map, and quantize the bottom map together with the decoded top code.
    z_top, commit_top = quantize_ema(h_top, vq_top)
    z_bottom, commit_bottom = quantize_ema(cat([h_bottom, dec_top(z_top)], -1), vq_bottom)

    # 3. Decode both maps and calculate the loss.
    x_recon = decoder(cat([upsample(z_top), z_bottom], -1))
    loss = (x_recon - x).square().mean() + commitment_cost * (commit_top + commit_bottom)  # Eq. 2 with EMA

def rejection_sample(samples, labels, classifier, keep_ratio):
    scores = classifier(samples).softmax(-1)[torch.arange(len(labels)), labels]
    keep = scores.argsort(descending=True)[: int(keep_ratio * len(samples))]
    return samples[keep]

def sample(prior_top, prior_bottom, decoder, vq_top, vq_bottom, labels):
    top = prior_top.sample(labels)  # 32 x 32 codes, PixelCNN with self-attention
    bottom = prior_bottom.sample(labels, top)  # 64 x 64 codes, conditioned on the top codes
    z_top, z_bottom = vq_top["codebook"][top], vq_bottom["codebook"][bottom]
    return decoder(cat([upsample(z_top), z_bottom], -1))

Neural Discrete Representation Learning

Aaron van den Oord (48,328), Oriol Vinyals (294,027), Koray Kavukcuoglu (256,343)

Nov 02, 2017      VQ-VAE (8,366)      code

It made learned discrete codes the input of generative models. Image, audio and video token models still start from its nearest-code quantizer and its two-stage recipe.

imageaudioautoregressiveunread

A VAE with a discrete latent: each encoder output maps to the nearest codebook vector, and a separate prior generates the codes.
Insight. First compress data into discrete tokens, then model the tokens. Most later token-based image generators follow this same route.

  • Codebook and quantization (§3.1, Eq. 2). The codebook e∈ℝK×D holds K vectors of dimension D. Each encoder output vector becomes its nearest entry, zq(x)=ek, k=argminj‖ze(x)−ej‖2, so the posterior q(z∣x) is one-hot Eq. (1). ImageNet uses K=512 code vectors.

  • Straight-through gradient (§3.2). The arg min has no gradient, so the backward pass copies the gradient of the decoder input to the encoder output: zq=ze+sg[zq−ze], where sg is the stop-gradient operator. It works because both vectors share one D-dimensional space.

  • Loss (§3.2, Eq. 3). L=logp(x∣zq(x))+‖sg[ze(x)]−e‖22+β‖ze(x)−sg[e]‖22 with β=0.25, and β from 0.1 to 2.0 gives the same results. Its terms (1) train the decoder and the encoder, (2) move e toward ze(x), and (3), the commitment loss, keep the encoder near its code.

  • Prior (§3.1, §3.3). Training keeps a uniform prior over the K codes, so the KL term is the constant logK and drops out. After training, a PixelCNN for images or a WaveNet for audio fits an autoregressive prior over the code map. The paper leaves joint training for future work.

  • Experiments (§4). On CIFAR-10 the VQ-VAE gets 4.67 bits/dim, near a continuous VAE (4.51) and ahead of the VIMCO estimator (5.14).

  • Codes match phonemes (§4.3). A map from the 128 speech codes to the 41 phonemes is 49.3% accurate, against 7.2% by chance.

def quantize(z_e, codebook):
    flat = z_e.reshape(-1, codebook.shape[1])
    distances = (flat ** 2).sum(1, keepdim=True) - 2 * flat @ codebook.T + (codebook ** 2).sum(1)
    indices = distances.argmin(1)  # Eq. 1
    z_q = codebook[indices].reshape(z_e.shape)  # Eq. 2
    return z_q, indices.reshape(z_e.shape[:-1])

def train(encoder, decoder, codebook, x, data_variance, commitment_cost=0.25):
    # 1. Encode the images and quantize each latent vector.
    z_e = encoder(x)
    z_q, _ = quantize(z_e, codebook)

    # 2. Calculate the codebook loss and the commitment loss.
    codebook_loss = (z_q - z_e.detach()).square().mean()
    commitment_loss = (z_q.detach() - z_e).square().mean()

    # 3. Copy the decoder-input gradient to the encoder, and reconstruct the images.
    z_q = z_e + (z_q - z_e).detach()  # straight-through estimator
    recon_loss = (decoder(z_q) - x).square().mean() / data_variance

    loss = recon_loss + codebook_loss + commitment_cost * commitment_loss  # Eq. 3

def sample(prior, decoder, codebook, shape):
    indices = prior.sample(shape)  # PixelCNN over the code map
    return decoder(codebook[indices])

Improved Mean Flows: On the Challenges of Fastforward Generative Models

Zhengyang Geng (3,092), Yiyang Lu (474), Zongze Wu (3,031), Eli Shechtman (76,014), J. Zico Kolter (76,576), Kaiming He (893,639)

CMU · MIT · Adobe · THU

Conference on Computer Vision and Pattern Recognition (CVPR), 2026

Dec 01, 2025      iMF (142)      code (359)

✓ reviewedimageflow

Recast the self-built target of MeanFlow as plain velocity regression, and make its fixed guidance scale one more condition at test time.
Insight. MeanFlow's target leaks the true velocity through its input. A setting fixed before training, like CFG, cannot change at test time.

  • MeanFlow's target (§3, Eq. 6–7). With noise e and data x, the average velocity u over [r,t], r≤t, and the instantaneous v satisfy u=v−(t−r)JVP(u;v) Eq. (4–5). MeanFlow fits utgt=(e−x)−(t−r)JVP(uθ;e−x) Eq. (6) by 𝔼‖uθ−sg(utgt)‖2 Eq. (7) (sg: stop-gradient).

  • An equivalent v-loss (§4.1, Eq. 9–10). Solve the identity for v, v=u+(t−r)du/dt Eq. (8), to get Vθ≜uθ+(t−r)JVPsg(uθ;e−x) Eq. (9), where JVPsg is its stop-gradient form. The loss 𝔼‖Vθ−(e−x)‖2 Eq. (10) is a v-loss re-parameterized by u-pred, equivalent to Eq. (6–7).

  • The illegitimate input (Eq. 11). In fact, Vθ is Vθ(zt,e−x). It uses the conditional velocity, which no regressor of zt may use.

  • Network-predicted tangent (Eq. 12). Vθ(zt)≜uθ(zt)+(t−r)JVPsg(uθ;vθ): both arguments are now network outputs of zt alone.

  • Two sources of vθ (§4.1). vθ uses the free boundary condition vθ(zt,t)≡uθ(zt,t,t) or an 8-layer v-head on a flow-matching loss.

  • Guidance as a condition (§4.2, Eq. 15). MeanFlow fixes the scale ω of the guided velocity for the class c, vcfg(zt∣c)=ωv(zt∣c)+(1−ω)v(zt) Eq. (13), before training. iMF makes ω an input, Vθ(·∣c,ω)≜uθ(zt∣c,ω)+(t−r)JVPsg Eq. (15), with ω~p(ω)∝ω−β on [1,8] for a skew β.

  • The guided target (App. A, Eq. 17). vtgt=(e−x)+(1−1/ω)(uθ(zt∣t,t,c)−uθ(zt∣t,t,∅)) for the null class ∅. ω=1 is no guidance.

  • Guidance interval (§4.2). Ω={ω,tmin,tmax} with tmin~U[0,0.5] and tmax~U[0.5,1]. Outside it, ω=1, and the r=t rows span [0,1].

  • In-context conditioning (Eq. 16). uθ(zt∣r,t,c,Ω) takes conditions as tokens, 8 for the class and 4 per other, without adaLN-zero.

  • Experiments (§5). On ImageNet-256 from scratch, iMF-XL/2 gets FID 1.72 at 1-NFE (MeanFlow-XL/2: 3.43) and 1.54 at 2-NFE.

  • Size labels mislead (Tab. 2). XL/2 costs 174.6 Gflops in iMF and 119.0 in MeanFlow. At similar FLOPs, M/2 gets 2.27 and 5.01.

def sample_time_steps(bs, time_mu=-0.4, time_sigma=1.0, ratio_r_not_equal_t=0.5):
    time_samples = torch.randn(bs, 2)
    time_samples = torch.sigmoid(time_samples * time_sigma + time_mu)

    sorted_samples, _ = torch.sort(time_samples, dim=1)  # make r < t
    r, t = sorted_samples[:, 0], sorted_samples[:, 1]

    # Set r to t with the probability of r = t.
    fraction_equal = 1.0 - ratio_r_not_equal_t
    equal_mask = torch.rand(bs) < fraction_equal
    r = torch.where(equal_mask, t, r)

    return r, t

def sample_cfg_scale(bs, cfg_beta=1.0, cfg_omega_max=8.0):
    u = torch.rand(bs)
    if cfg_beta == 1.0:
        return torch.exp(u * math.log(cfg_omega_max))

def sample_time_steps(bs, time_mu=-0.4, time_sigma=1.0, ratio_r_equal_t=0.5):
    def logit_normal(n):
        return torch.sigmoid(torch.randn(n) * time_sigma + time_mu)

    n_equal = int(bs * ratio_r_equal_t)
    t_equal = logit_normal(n_equal)  # r = t
    t_1, t_2 = logit_normal(bs - n_equal), logit_normal(bs - n_equal)
    t = cat([t_equal, torch.maximum(t_1, t_2)])
    r = cat([t_equal, torch.minimum(t_1, t_2)])  # make r < t

    return r, t

def sample_alpha(k, k_s=600_000, k_e=1_000_000, gamma=25.0, eta=5e-3):

    if alpha < eta:

    return 1.0 if alpha > 1 - eta else alpha

    cfg_w=0.2, cfg_kappa=0.92, cfg_min_t=0.0, cfg_max_t=0.75, cfg_prob=0.1,
    clamp_target=4.0, adaptive_eps=1e-3
):
    # 1. Sample the timesteps r and t, the ratio alpha and the intermediate timestep s.
    r, t = sample_time_steps(bs)
    alpha = sample_alpha(k)
    s = alpha * r + (1 - alpha) * t

    # 2. Build the noisy latent z_t and its velocity v_t.

    z_t = (1 - t) * z_0 + t * noise  # linear path
    v_t = noise - z_0  # conditional velocity

    tau = torch.randn(bs) * p_std + p_mean
    return torch.arctan(torch.exp(tau) / sigma_d)  # log-normal proposal on sigma_d tan(t)

def train(
    model, weight_net, teacher, x_0, iters, consistency_training=False,
    sigma_d=0.5, c=0.1, warmup_iters=10000, cfg_max=2.0
):
    # 1. Sample t and build the TrigFlow sample x_t.
    t = sample_time(bs)
    z = torch.randn_like(x_0) * sigma_d
    x_t = cos(t) * x_0 + sin(t) * z

    # 2. Get the ODE direction from the pair for sCT, or from the guided teacher for sCD.
    s = rand(bs) * (cfg_max - 1) + 1  # guidance scale, also a student input
    if consistency_training:
        dxdt = cos(t) * z - sin(t) * x_0
    else:
        dxdt = sigma_d * teacher(x_t / sigma_d, t, s)  # Eq. 3

    # 3. Run the student, and run its stop-gradient copy through the rearranged JVP.
    F = model(x_t / sigma_d, t, s)
    tangent = (cos(t) * sin(t) * dxdt, cos(t) * sin(t) * sigma_d)
    with no_grad():
        F_sg, cs_dFdt = jvp(lambda x, t_: model(x, t_, s), (x_t / sigma_d, t), tangent)

    # 4. Build the warmed-up tangent and normalize it.
    r = min(1.0, iters / warmup_iters)
    g = -cos(t) ** 2 * (sigma_d * F_sg - dxdt) - r * (cos(t) * sin(t) * x_t + cs_dFdt)  # Eq. 6 times cos(t)
    g = g / (g.flatten(1).norm(dim=1) + c)

    # 5. Calculate the adaptive-weighted loss.
    w, D = weight_net(t), x_0[0].numel()
    loss = (exp(w) / D * (F - F_sg - g).square().flatten(1).sum(1) - w).mean()  # Eq. 8

def noise_pyramid(noise, stages=3):
    pyramid = [noise]
    for _ in range(stages - 1):
        pyramid.append(2 * interpolate(pyramid[-1], scale_factor=0.5, mode="bilinear"))  # 2x keeps unit variance
    return pyramid[::-1]  # coarse to fine

def stage_sigmas(stages=3, stage_range=(0, 1 / 3, 2 / 3, 1), gamma=1 / 3):
    start, end = [], []
    for k in range(stages):
        s = 1 - stage_range[k]  # noise level where stage k starts on the global schedule
        if k > 0:
            signal = 1 - s
            s = 1 - signal / (sqrt(1 + 1 / gamma) * (1 - signal) + signal)  # corrected so Eq. 15 holds
        start.append(s)
        end.append(1 - stage_range[k + 1])
    dist = [s - e for s, e in zip(start, end)]
    bounds = [sum(dist[:k]) / sum(dist) for k in range(stages + 1)]  # each stage's share of the timestep axis
    return start, end, bounds

def stage_timestep(r, k, bounds, num_train_timesteps=1000):
    return num_train_timesteps * (1 - bounds[k] - (1 - r) * (bounds[k + 1] - bounds[k]))

def history_condition(latents, k, num_units, frame_per_unit=1, corrupt_ratio=1 / 3):
    sigma = torch.rand(bs) * corrupt_ratio  # t' ~ U[0, 1/3]
    corrupt = lambda clip: sigma * torch.randn_like(clip) + (1 - sigma) * clip
    hist, j, stage = [], 1, k
    while j < num_units and (j == 1 or stage > 0):  # j units back, one stage coarser each
        hist.append(corrupt(latents[stage][:, :, -(j + 1) * frame_per_unit:-j * frame_per_unit]))  # Eq. 16
        j, stage = j + 1, max(stage - 1, 0)
    if j < num_units:
        hist.append(corrupt(latents[0][:, :, :-j * frame_per_unit]))  # the rest at the coarsest stage
    return hist[::-1]

def past_condition(history, k):
    scales = [0.5 ** (2 - max(k - j, 0)) for j in range(len(history))]
    return [interpolate(h, scale_factor=s) for h, s in zip(history[::-1], scales)][::-1]  # Eq. 17

def block_noise(x, gamma=1 / 3):
    cov = torch.eye(4) * (1 + gamma) - torch.ones(4, 4) * gamma  # Sigma' of Eq. 14, per 2x2 block
    n = MultivariateNormal(torch.zeros(4), cov).sample(x.shape[:-2] + (x.shape[-2] // 2, x.shape[-1] // 2))
    return rearrange(n, "... h w (p q) -> ... (h p) (w q)", p=2, q=2)

def train(model, latents, text, num_units, sample_ratios=(1.0, 2.0, 1.0), frame_per_unit=1):
    # 1. Build the noise pyramid from one Gaussian noise. The list latents holds the clip at each stage's resolution.
    noise = noise_pyramid(torch.randn_like(latents[-1]))
    start_sigma, end_sigma, bounds = stage_sigmas()

    # 2. Pick a stage and build its endpoints from the shared noise.
    k = torch.multinomial(torch.tensor(sample_ratios), 1).item()
    coarse = interpolate(latents[k - 1], scale_factor=2, mode="nearest") if k > 0 else 0
    start = start_sigma[k] * noise[k] + (1 - start_sigma[k]) * coarse  # Eq. 10, pure noise at k = 0
    end = end_sigma[k] * noise[k] + (1 - end_sigma[k]) * latents[k]  # Eq. 9, the clean latent at k = 2

    # 3. Interpolate inside the stage and map the position to the model's timestep.
    r = torch.rand(bs)  # 1 at the stage's start, 0 at its end
    x_t = r * start + (1 - r) * end  # Eq. 6
    t = stage_timestep(r, k, bounds)

    # 4. Keep the newest unit as the trained one and condition it on the corrupted history.
    x_t, target = x_t[:, :, -frame_per_unit:], (start - end)[:, :, -frame_per_unit:]
    hist = history_condition(latents, k, num_units)
    text = where(rand(bs) < 0.1, "", text)  # 10% text dropout

    # 5. Regress the stage displacement on the newest unit.
    v = model(cat(hist + [x_t], dim=2), t, text)[:, :, -frame_per_unit:]  # blockwise causal attention
    loss = (v - target).square().mean()  # Eq. 11

def sample(
    model, text, num_units,
    steps=(20, 20, 20), video_steps=(10, 10, 10), guidance=7.0, video_guidance=5.0
):
    start_sigma, _, bounds = stage_sigmas()
    history = []
    for unit in range(num_units):
        x = torch.randn(low_res_shape)  # stage 0 starts from noise at the coarsest resolution
        n_steps, scale = (steps, guidance) if unit == 0 else (video_steps, video_guidance)
        for k in range(3):
            if k > 0:
                s_k = 1 - start_sigma[k]  # the stage's corrected start signal
                up = interpolate(x, scale_factor=2, mode="nearest")
                x = (1 + s_k) / 2 * up + sqrt(3) * (1 - s_k) / 2 * block_noise(up)  # Eq. 15
            rs = linspace(1, 0, n_steps[k] + 1)
            for r, r_next in zip(rs[:-1], rs[1:]):
                inp, t = cat(past_condition(history, k) + [x], dim=2), stage_timestep(r, k, bounds)
                v_c, v_u = model(inp, t, text)[:, :, -1:], model(inp, t, "")[:, :, -1:]
                x = x + (r_next - r) * (v_u + scale * (v_c - v_u))  # Euler step
        history.append(x)
    return cat(history, dim=2)

def phi(k, z, convs, num_scales=10, resi_ratio=0.5):
    ticks = torch.linspace(1 / 12, 11 / 12, len(convs))  # 4 shared convolutions
    conv = convs[(ticks - k / (num_scales - 1)).abs().argmin()]
    return (1 - resi_ratio) * z + resi_ratio * conv(z)

def upsample(e, pn, size):
    return F.interpolate(e.transpose(1, 2).unflatten(2, (pn, pn)), size=(size, size), mode="bicubic")

def multi_scale_tokens(f, codebook, convs, patch_nums=(1, 2, 3, 4, 5, 6, 8, 10, 13, 16)):
    tokens, size = [], patch_nums[-1]
    for k, pn in enumerate(patch_nums):
        rest = F.interpolate(f, size=(pn, pn), mode="area").flatten(2).transpose(1, 2)
        r_k = torch.cdist(rest, codebook).argmin(-1)  # Eq. 3, the nearest code
        tokens.append(r_k)
        f = f - phi(k, upsample(codebook[r_k], pn, size), convs)  # Alg. 1 line 9
    return tokens

def reconstruct(tokens, codebook, convs, decoder, patch_nums=(1, 2, 3, 4, 5, 6, 8, 10, 13, 16)):
    f_hat = 0
    for k, (r_k, pn) in enumerate(zip(tokens, patch_nums)):
        f_hat = f_hat + phi(k, upsample(codebook[r_k], pn, patch_nums[-1]), convs)  # Alg. 2 line 8
    return decoder(f_hat)

def next_scale_inputs(tokens, codebook, convs, patch_nums=(1, 2, 3, 4, 5, 6, 8, 10, 13, 16)):
    f_hat, inputs = 0, []
    for k in range(len(patch_nums) - 1):
        f_hat = f_hat + phi(k, upsample(codebook[tokens[k]], patch_nums[k], patch_nums[-1]), convs)
        pn = patch_nums[k + 1]
        inputs.append(F.interpolate(f_hat, size=(pn, pn), mode="area").flatten(2).transpose(1, 2))
    return cat(inputs, dim=1)

def block_causal_mask(patch_nums=(1, 2, 3, 4, 5, 6, 8, 10, 13, 16)):
    scale = cat([full((pn * pn,), k) for k, pn in enumerate(patch_nums)])
    return scale[:, None] >= scale[None, :]  # r_k attends to r_<=k

def train(model, encoder, codebook, convs, images, labels, num_classes=1000, cond_drop_rate=0.1):
    # 1. Tokenize the images, and build the teacher-forced inputs.
    with no_grad():
        tokens = multi_scale_tokens(encoder(images), codebook, convs)
        x = next_scale_inputs(tokens, codebook, convs)

    # 2. Drop labels for the guidance.
    labels = where(rand(bs) < cond_drop_rate, num_classes, labels)  # the null class

    # 3. Predict all scales at once, and calculate the cross-entropy over all 680 tokens.
    logits = model(labels, x, mask=block_causal_mask())  # Eq. 6
    loss = F.cross_entropy(logits.flatten(0, 1), cat(tokens, dim=1).flatten())

def sample(model, codebook, convs, decoder, labels, patch_nums=(1, 2, 3, 4, 5, 6, 8, 10, 13, 16),
           cfg=1.5, top_k=900, top_p=0.96, num_classes=1000):

    null = full_like(labels, num_classes)
    for k, pn in enumerate(patch_nums):
        logits_c, logits_u = model(cat([labels, null]), x, scale=k).chunk(2)  # KV cache, no mask
        s = cfg * k / (K - 1)  # the guidance grows with the scale, k counts from 0
        r_k = sample_top_k_top_p((1 + s) * logits_c - s * logits_u, top_k, top_p)
        f_hat = f_hat + phi(k, upsample(codebook[r_k], pn, patch_nums[-1]), convs)
        if k < K - 1:
            x = F.interpolate(f_hat, size=(patch_nums[k + 1],) * 2, mode="area").flatten(2).transpose(1, 2)
            x = x.repeat(2, 1, 1)  # the conditional and the null halves
    return decoder(f_hat)

def karras_t(ramp, sigma_min=0.002, sigma_max=80.0, rho=7.0):
    return (sigma_max ** (1 / rho) + ramp * (sigma_min ** (1 / rho) - sigma_max ** (1 / rho))) ** rho

def sample_indices(bs, num_scales=40, max_heun_steps=20):
    p = torch.arange(1, max_heun_steps + 1).float()  # p(k) proportional to k
    k = torch.multinomial(p / p.sum(), 1).item() + 1  # one teacher step count per batch
    n_t = torch.randint(0, num_scales - k, (bs,))
    n_u = n_t + k
    n_s = n_u + (torch.rand(bs) * (num_scales - n_u)).long()  # s uniform on the grid below u
    return n_t, n_u, n_s, k

def sample_dsm_sigmas(bs, p_mean=-1.2, p_std=1.2, ramp_max=0.7):
    sigma_lognormal = torch.exp(p_mean + p_std * torch.randn(bs // 2))
    sigma_high = karras_t(torch.rand(bs - bs // 2) * ramp_max)  # high noise of the grid
    return torch.cat([sigma_lognormal, sigma_high])

def jump(net, x_t, t, s, sigma_data=0.5):
    c_in = 1 / (t ** 2 + sigma_data ** 2) ** 0.5
    c_skip = sigma_data ** 2 / (t ** 2 + sigma_data ** 2)
    c_out = t * sigma_data / (t ** 2 + sigma_data ** 2) ** 0.5
    g = c_skip * x_t + c_out * net(c_in * x_t, 250 * log(t), 250 * log(s))  # EDM scalings
    return g, s / t * x_t + (1 - s / t) * g  # g and the neural jump G

def heun_solve(teacher, x, n_t, k, num_scales=40):
    for i in range(k):
        t = karras_t((n_t + i) / (num_scales - 1))
        t_next = karras_t((n_t + i + 1) / (num_scales - 1))
        d = (x - teacher(x, t)) / t  # Eq. 1
        x_euler = x + (t_next - t) * d
        d_next = (x_euler - teacher(x_euler, t_next)) / t_next  # Eq. 1
        x = x + (t_next - t) * (d + d_next) / 2
    return x

def adaptive_weight(loss_ctm, loss_other, last_layer):
    grad_ctm = torch.autograd.grad(loss_ctm, last_layer, retain_graph=True)[0]
    grad_other = torch.autograd.grad(loss_other, last_layer, retain_graph=True)[0]
    return (grad_ctm.norm() / (grad_other.norm() + 1e-4)).clamp(0, 1e4).detach()  # lambda of §3.3

def train(
    net, net_ema, teacher, disc, x_0, last_layer, step,
    num_scales=40, sigma_min=0.002, sigma_data=0.5, mu=0.999, gan_start=10000
):
    # 1. Sample the times t > u >= s on the grid.
    n_t, n_u, n_s, k = sample_indices(bs)
    t, u, s = (karras_t(n / (num_scales - 1)) for n in (n_t, n_u, n_s))

    # 2. Add noise to the data at time t.
    noise = torch.randn_like(x_0)
    x_t = x_0 + t * noise

    # 3. Jump from t to s with the student, and then to time 0 with the EMA student.
    _, G_ts = jump(net, x_t, t, s)
    x_est = jump(net_ema, G_ts, s, sigma_min)[1]

    # 4. Solve the teacher ODE from t to u, jump to s, and then jump to time 0.
    with no_grad():
        x_u = heun_solve(teacher, x_t, n_t, k)
        x_target = jump(net_ema, jump(net, x_u, u, s)[1], s, sigma_min)[1]  # Eq. 3
    loss_ctm = lpips(resize(x_est, 224), resize(x_target, 224)).mean()

    # 5. Calculate the DSM loss of g at s = t.
    sigma = sample_dsm_sigmas(bs)
    g, _ = jump(net, x_0 + sigma * torch.randn_like(x_0), sigma, sigma)
    weight = (sigma ** 2 + sigma_data ** 2) / (sigma * sigma_data) ** 2  # EDM weighting
    loss_dsm = (weight * (g - x_0).square()).flatten(1).mean(1).mean()
    loss = loss_ctm + adaptive_weight(loss_ctm, loss_dsm, last_layer) * loss_dsm

    # 6. Add the GAN loss of a two-jump sample after the warm-up.
    if step >= gan_start:
        x_fake = jump(net, G_ts, s, sigma_min)[1]
        loss_gan = -torch.stack([logit.mean() for logit in disc(x_fake)]).mean()
        loss = loss + adaptive_weight(loss_ctm, loss_gan, last_layer).clip(0.01, 10) * loss_gan

    # 7. Update the EMA student.
    net_ema = mu * net_ema + (1 - mu) * net  # stop-gradient EMA

def karras_sigmas(n, num_scales, sigma_min=0.002, sigma_max=80.0, rho=7.0):
    return (sigma_max ** (1 / rho) + n / (num_scales - 1) * (sigma_min ** (1 / rho) - sigma_max ** (1 / rho))) ** rho

def ct_schedule(step, total_steps=800000, start_ema=0.95, start_scales=2, end_scales=200):
    scales = ceil(sqrt(step / total_steps * ((end_scales + 1) ** 2 - start_scales ** 2) + start_scales ** 2) - 1)
    scales = max(scales, 1)
    mu = exp(start_scales * log(start_ema) / scales)  # EMA rate rises with N
    return scales + 1, mu

def f(net, x_t, sigma, sigma_min=0.002, sigma_data=0.5):
    c_skip = sigma_data ** 2 / ((sigma - sigma_min) ** 2 + sigma_data ** 2)
    c_out = (sigma - sigma_min) * sigma_data / (sigma ** 2 + sigma_data ** 2) ** 0.5
    c_in = 1 / (sigma ** 2 + sigma_data ** 2) ** 0.5
    return c_skip * x_t + c_out * net(c_in * x_t, 250 * log(sigma))  # Eq. 5, c_skip = 1 and c_out = 0 at sigma_min

def train(theta, theta_ema, teacher, x, step, distill=True, num_scales=40, mu=0.95):

    if not distill:

    # 2. Pick adjacent levels t > t2 of the N-level grid, and add noise to the image at level t.
    n = torch.randint(0, num_scales - 1, (bs,))
    t, t2 = karras_sigmas(n, num_scales), karras_sigmas(n + 1, num_scales)
    noise = torch.randn_like(x)
    x_t = x + t * noise

    pred = f(theta, x_t, t)  # dropout RNG state saved here

    with no_grad():

            x_t2 = x_t + (t2 - t) * d

Insight. The generator holds its own guidance signal: the gap between its two predictions. It became a default of conditional sampling.

  • Continuous-time diffusion (§2, Eq. 5). zλ=αλx+σλϵ adds the noise ϵ~𝒩(0,I) to the data x, with αλ2=1/(1+e−λ) and σλ2=1−αλ2 Eq. (1), where λ is the log signal-to-noise ratio. The network ϵθ(zλ,c) with the condition c, a class label here, trains with 𝔼‖ϵθ(zλ,c)−ϵ‖2 Eq. (5).

  • Noise levels (§2). λ=−2logtan(au+b) for u~U[0,1], where a,b bound λ to [λmin,λmax]=[−20,20]: a hyperbolic secant density.

  • Sampler mean (§2, Eq. 3). Ancestral steps run up λmin=λ1<…<λT=λmax, at uniform u, from zλ1~𝒩(0,I). From zλ to λ′, the mean is eλ−λ′(αλ′/αλ)zλ+(1−eλ−λ′)αλ′xθ Eq. (3): the forward posterior mean, with the prediction xθ=(zλ−σλϵθ)/αλ in place of the data x.

  • Sampler variance (§2, Eq. 4). With the reverse variance s~=(1−eλ−λ′)σλ′2 and the forward variance s=(1−eλ−λ′)σλ2, the step variance is s~1−vsv, a log-space interpolation, with v=0.2 at 128×128, where v=0 keeps the reverse variance. The last step outputs xθ(zλmax).

  • Classifier guidance (§3.1). A classifier pθ(c∣zλ) gives ϵ~θ=ϵθ(zλ,c)−wσλ∇zλlogpθ(c∣zλ). The samples then follow p~θ(zλ∣c)∝pθ(zλ∣c)pθ(c∣zλ)w: less diverse and more faithful to c. It needs this second network, which trains on noisy zλ for guidance.

  • Joint training (§3.2, Alg. 1). Training replaces c by a null token ∅ with puncond=0.1, so one network also gives ϵθ(zλ)=ϵθ(zλ,∅).

  • Implicit classifier (§3.2). With exact scores, pi(c∣zλ)∝p(zλ∣c)/p(zλ) has ∇zλlogpi=−(ϵ*(zλ,c)−ϵ*(zλ))/σλ. Classifier guidance with pi then gives (1+w)ϵ*(zλ,c)−wϵ*(zλ). But the network difference is no classifier gradient in general, so the step is no attack on a classifier.

  • Classifier-free guidance (§3.2, Eq. 6). ϵ~θ(zλ,c)=(1+w)ϵθ(zλ,c)−wϵθ(zλ) replaces ϵθ at sampling, with two forward passes per step and w=0.3 for the best 128×128 FID. w=0 is the plain conditional model, and any sampler, DDIM too, can use the guided prediction.

  • Experiments (§4). On class-conditional ImageNet 128×128 with ADM's network, w=0.3 gets FID 2.43 (classifier-guided ADM-G: 2.97).

  • A little unconditional training is enough (§4.2). puncond=0.1 and 0.2 give the same IS–FID frontier, and 0.5 is worse everywhere on it.

  • Equal compute loses (§4.3). Two passes per step make 128 steps cost what ADM-G's 256 do, and the best FID is 3.02 (ADM-G: 2.97).

def sample_log_snr(u, lambda_min=-20.0, lambda_max=20.0):
    b = math.atan(math.exp(-lambda_max / 2))
    a = math.atan(math.exp(-lambda_min / 2)) - b
    return -2 * torch.log(torch.tan(a * u + b))  # bounded hyperbolic secant

def alpha_sigma(lam):
    alpha2 = torch.sigmoid(lam)  # Eq. 1
    return alpha2.sqrt(), (1 - alpha2).sqrt()

def train(model, x, c, p_uncond=0.1):
    # 1. Drop the condition with the probability p_uncond.
    c = torch.where(torch.rand(bs) < p_uncond, null, c)

    # 2. Sample a log SNR and corrupt the data.
    lam = sample_log_snr(torch.rand(bs))
    alpha, sigma = alpha_sigma(lam)
    noise = torch.randn_like(x)
    z = alpha * x + sigma * noise

    # 3. Predict the noise.
    loss = (model(z, lam, c) - noise).square().mean()  # Eq. 5

def sample(model, c, w=0.3, num_steps=256, v=0.2):
    lams = sample_log_snr(torch.linspace(1, 0, num_steps))  # increasing log SNR, uniform in u
    z = torch.randn(shape)
    for t in range(num_steps):
        alpha, sigma = alpha_sigma(lams[t])
        eps = (1 + w) * model(z, lams[t], c) - w * model(z, lams[t], null)  # Eq. 6
        x = (z - sigma * eps) / alpha
        if t == num_steps - 1:
            return x

        # Take one ancestral step to the next log SNR.
        alpha_next, sigma_next = alpha_sigma(lams[t + 1])
        r = torch.exp(lams[t] - lams[t + 1])  # e^(lambda - lambda')
        mean = r * (alpha_next / alpha) * z + (1 - r) * alpha_next * x  # Eq. 3
        var = ((1 - r) * sigma_next ** 2) ** (1 - v) * ((1 - r) * sigma ** 2) ** v  # Eq. 4
        z = mean + var.sqrt() * torch.randn_like(z)

imagediffusionunread

A modular design space for diffusion: sampler, schedule, preconditioning and loss weighting become choices that change one at a time.
Insight. A split into independent choices is a contribution itself. Later work states its schedule, sampler and preconditioning in these terms.

  • Probability-flow ODE and denoiser (§2, Eq. 1–3). The ODE dx=−σ˙σ∇xlogp(x;σ)dt Eq. (1) needs only a score. A denoiser D gives it as (D−x)/σ2 Eq. (3) and trains with 𝔼‖D(y+n;σ)−y‖2 Eq. (2) on images y with noise n~𝒩(0,σ2I). σ˙ is the rate of the noise level σ(t).

  • Schedule σ(t)=t (§3, Eq. 4). For the scale s(t)=1, dx/dt=(x−D(x;t))/t, and one Euler step to t=0 gives the denoised image.

  • Heun sampler (§3, Alg. 1). With slopes di at ti and di′ at the Euler endpoint, xi+1=xi+(ti+1−ti)(di+di′)/2. The last step is Euler.

  • Step discretization (§3, Eq. 5). σi<N=(σmax1/ρ+iN−1(σmin1/ρ−σmax1/ρ))ρ with σmin=0.002, σmax=80, ρ=7: steps are shorter near σmin.

  • Stochastic sampler (§4, Alg. 2). Before each step, add new noise, scaled by Snoise slightly above 1, to raise the level to t^i=ti+γiti with γi=min(Schurn/N,2−1) inside [Stmin,Stmax]. Then take a Heun step. The noise corrects earlier errors, and Schurn=0 gives Alg. 1.

  • Preconditioning (§5, Eq. 7–8). The denoiser is Dθ(x;σ)=cskipx+coutFθ(cinx;cnoise) Eq. (7) with the network Fθ, so the loss Eq. (8) regresses (y−cskipx)/cout. cin,cout give unit variance, cskip=σdata2/(σ2+σdata2) minimizes cout to limit the network error, and cnoise=ln(σ)/4.

  • Weighting and noise levels (§5). λ(σ)=1/cout2=(σ2+σdata2)/(σσdata)2 gives unit initial loss. lnσ~𝒩(−1.2,1.22) aims where loss falls.

  • Non-leaking augmentation (§5). Augmentation parameters condition Fθ and are zero at sampling, so augmentations do not leak.

  • Experiments (§3, §5). On CIFAR-10 and ImageNet-64, the sampler takes ImageNet FID 2.07 → 1.55, and retraining gets 1.36.

  • Better models need less churn (Fig. 5). On CIFAR-10, churn helps old models and hurts retrained ones. ImageNet-64 still needs it.

def karras_sigmas(num_steps=18, sigma_min=0.002, sigma_max=80, rho=7):
    i = torch.arange(num_steps)
    lo, hi = sigma_min ** (1 / rho), sigma_max ** (1 / rho)
    t = (hi + i / (num_steps - 1) * (lo - hi)) ** rho  # Eq. 5
    return cat([t, zeros(1)])  # t_N = 0

def denoise(model, x, sigma, label, aug=None, sigma_data=0.5):
    c_skip = sigma_data ** 2 / (sigma ** 2 + sigma_data ** 2)
    c_out = sigma * sigma_data / (sigma ** 2 + sigma_data ** 2).sqrt()
    c_in = 1 / (sigma ** 2 + sigma_data ** 2).sqrt()
    return c_skip * x + c_out * model(c_in * x, sigma.log() / 4, label, aug)  # Eq. 7

def train(model, x, label, p_mean=-1.2, p_std=1.2, sigma_data=0.5):
    # 1. Draw one noise level per image from the log-normal distribution.
    sigma = (torch.randn(bs) * p_std + p_mean).exp()

    # 2. Add noise to an augmented image. Its augmentation parameters condition the network.
    y, aug = augment(x)  # aug is zero at sampling time
    x_t = y + torch.randn_like(y) * sigma

    # 3. Denoise through the preconditioning and weight the error by 1 / c_out^2.
    weight = (sigma ** 2 + sigma_data ** 2) / (sigma * sigma_data) ** 2
    loss = (weight * (denoise(model, x_t, sigma, label, aug) - y) ** 2).mean()  # Eq. 8

def sample(model, label, num_steps=18, s_churn=0, s_tmin=0, s_tmax=float("inf"), s_noise=1):
    t = karras_sigmas(num_steps)
    x = torch.randn(shape) * t[0]
    for i in range(num_steps):
        gamma = min(s_churn / num_steps, sqrt(2) - 1) if s_tmin <= t[i] <= s_tmax else 0  # Alg. 2, 0 gives Alg. 1
        t_hat = t[i] * (1 + gamma)
        x_hat = x + (t_hat ** 2 - t[i] ** 2).sqrt() * s_noise * torch.randn_like(x)
        d = (x_hat - denoise(model, x_hat, t_hat, label)) / t_hat  # Eq. 4 with sigma(t) = t
        x = x_hat + (t[i + 1] - t_hat) * d  # Euler step
        if i < num_steps - 1:
            d_next = (x - denoise(model, x, t[i + 1], label)) / t[i + 1]
            x = x_hat + (t[i + 1] - t_hat) * (d + d_next) / 2  # Heun correction
    return x

def compute_alpha(betas, t):
    alphas = cat([ones(1), torch.cumprod(1 - betas, dim=0)])  # alpha_0 = 1
    return alphas[t + 1].view(-1, 1, 1, 1)

def train(model, x_0):
    betas = linear_betas()

    # 1. Sample the timesteps in antithetic pairs t and T - 1 - t.
    t = torch.randint(0, len(betas), (bs // 2 + 1,))
    t = cat([t, len(betas) - t - 1])[:bs]

    # 2. Add the noise to the images in one step.
    noise = torch.randn_like(x_0)
    a = compute_alpha(betas, t)
    x_t = a.sqrt() * x_0 + (1 - a).sqrt() * noise  # Eq. 4

    # 3. Predict the noise and calculate the squared error.
    loss = (noise - model(x_t, t)).square().sum(dim=(1, 2, 3)).mean()  # Eq. 5 with gamma = 1

    for i, j in zip(reversed(seq), reversed(seq_next)):

def linear_schedule(num_steps=1000, beta_start=1e-4, beta_end=0.02):
    betas = torch.linspace(beta_start, beta_end, num_steps, dtype=torch.float64)
    alphas_cumprod = torch.cumprod(1 - betas, dim=0)  # alpha_bar_t
    alphas_cumprod_prev = cat([ones(1), alphas_cumprod[:-1]])  # alpha_bar_{t-1}
    return betas, alphas_cumprod, alphas_cumprod_prev

def train(model, x_0):
    betas, alphas_cumprod, _ = linear_schedule()

    # 1. Sample one timestep per image and the noise.
    t = torch.randint(0, len(betas), (bs,))
    noise = torch.randn_like(x_0)

    # 2. Add the noise to the images in one step.
    a_bar = alphas_cumprod[t].view(-1, 1, 1, 1)
    x_t = a_bar.sqrt() * x_0 + (1 - a_bar).sqrt() * noise  # Eq. 4

    # 3. Predict the noise and calculate the unweighted squared error.
    loss = (noise - model(x_t, t)).square().mean()  # Eq. 14

def sample(model):
    betas, alphas_cumprod, alphas_cumprod_prev = linear_schedule()
    coef_x0 = betas * alphas_cumprod_prev.sqrt() / (1 - alphas_cumprod)  # Eq. 7
    coef_xt = (1 - alphas_cumprod_prev) * (1 - betas).sqrt() / (1 - alphas_cumprod)  # Eq. 7
    x = torch.randn(shape)
    for i in reversed(range(len(betas))):
        eps = model(x, full((bs,), i))
        x_0 = (x - (1 - alphas_cumprod[i]).sqrt() * eps) / alphas_cumprod[i].sqrt()  # Eq. 15
        mean = coef_x0[i] * x_0.clamp(-1, 1) + coef_xt[i] * x  # Eq. 11 when nothing is clipped
        x = mean + betas[i].sqrt() * torch.randn_like(x) if i > 0 else mean  # sigma_t^2 = beta_t
    return x
